# Q-0002: Общая политика Editor Controls

- **Статус:** Открыт
- **Создан:** 2026-10-13
- **Обновлён:** 2026-10-13

## Идея или вопрос

Позже рассмотреть подготовленные правила Editor Controls и определить, какие ещё настройки нужно ограничить или оставить доступными.

## Контекст

Владелец назвал Editor Controls среди отложенных тем. Часть настроек уже реализована отдельными ADR: палитра цветов, шкала расстояний, типографика и ограничения Heading/Paragraph. Общая политика ещё не принята целиком.

Связанные решения: [ADR-0018](../adr/0018-site-palette-only.md), [ADR-0020](../adr/0020-site-spacing-only.md), [ADR-0023](../adr/0023-typography-controls.md), [ADR-0024](../adr/0024-heading-block-contract.md), [ADR-0025](../adr/0025-paragraph-block-contract.md).

## Для обсуждения

- Какие правила действуют глобально, а какие — только для отдельных блоков?
- Что осталось определить для градиентов, duotone, decoration и других controls?
- Как сохранять согласованный дизайн, не лишая редактора необходимых действий?
- Какие примеры старого документа расходятся с принятыми ADR?

## Результат

Общая политика принята в [ADR-0034](../adr/0034-pattern-led-editor.md): стандартные настройки дизайна скрываются глобально. Вопрос остаётся открытым для проверки удобства паттернов, возможного возвращения только padding/gap и поведения сторонних блоков.
