# Q-0006: Отдельный плагин иконок

- **Статус:** Реализован
- **Создан:** 2026-10-13
- **Обновлён:** 2026-10-14

## Идея или вопрос

Владелец планирует отдельный плагин для иконок. Обсудить его структуру, коллекции, API подключения, выбор иконок в готовых паттернах и состав передачи клиенту. Сейчас плагин не создавать.

## Контекст

Тема сохранена по просьбе владельца после оценки старой темы. Решение о реализации пока не принято.

## Для обсуждения

Какое минимальное решение соответствует цели проекта и действующим ADR? Как готовые паттерны будут использовать эту возможность без ручной настройки оформления?

## Результат

2026-10-14: вместо отдельного плагина принят и реализован встроенный модуль includes/icons Celestial по [ADR-0042](../adr/0042-lucide-icons-module.md) и [ADR-0043](../adr/0043-vendored-ready-icon-assets.md). Все 2141 SVG проходят серверный рендер; окончательный выбор в UI требует ручной проверки из-за пустого canvas тестового браузера.

## История

- 2026-10-13 — Тема сохранена для дальнейшего обсуждения.

- 2026-10-14 — Владелец подтвердил перенос готового dist внутрь Celestial; отдельный плагин не создаётся.
