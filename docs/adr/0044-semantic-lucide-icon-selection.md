# ADR-0044: Выбор иконок Lucide по смыслу содержимого

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Автор решения:** Владелец проекта

## Контекст

В Celestial встроена коллекция Lucide. Владелец хочет, чтобы агент при работе с дизайном выбирал иконки именно из установленного набора и подбирал их логично под контекст и смысл блока.

## Решение

Для новых и адаптируемых дизайнов, паттернов и содержимого использовать иконки коллекции lucide вместо стандартной коллекции WordPress. Сначала определить смысл элемента: действие, предмет, преимущество или состояние. Затем найти подходящую иконку в wordpress/plugin/includes/icons/assets/manifest.php по английскому имени и подписи, проверить существование SVG и оценить его визуальную понятность в контексте.

Manifest содержит имена и краткие подписи, а не подробные описания назначения: не выбирать только по совпадению слова. Предпочитать понятную аудитории метафору и согласованное использование одной иконки для одного смысла в проекте. Не вставлять декоративные иконки без задачи и не подменять ими необходимый текст. Если подходящей иконки нет, оставить текст или сообщить владельцу; не подключать другой набор автоматически.

В разметке использовать существующие идентификаторы lucide/<name> и core/icon. Для смысловой иконки без текстовой подписи задавать доступное имя; декоративную не озвучивать как самостоятельное содержимое. Цвет, размер и расположение определяются оформлением темы и композиции, без включения controls дизайна.

Правило относится к создаваемому оформлению сайта. Оно не требует заменять служебные иконки интерфейса WordPress, отключать стандартную коллекцию или менять уже сохранённый контент без поручения.

## Альтернативы

Выбирать произвольный набор либо стандартные иконки WordPress. Это нарушает выбранную визуальную согласованность и добавляет непредусмотренные зависимости.

## Последствия

Агент использует известный локальный каталог и объяснимый выбор. Оценка смысла и доступности нужна для каждого применения; автоматическое совпадение имени не гарантирует подходящую иконку.
