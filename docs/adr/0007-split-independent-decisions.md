# ADR-0007: Разделение независимых решений на отдельные ADR

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

Одно сообщение пользователя может содержать несколько архитектурных решений. Объединение независимых выборов в одну запись затрудняет их последующий пересмотр.

## Решение

Агент самостоятельно выделяет независимые решения и оформляет каждое отдельным ADR, даже если пользователь изложил их одним сообщением. Критерий — возможность пересмотреть один выбор, сохранив остальные.

Связанные детали одного решения хранить вместе: например, разделение темы и плагина, их ответственность и пути каталогов. Не создавать отдельные ADR для мелких деталей реализации. Проверку противоречий и согласование замены проводить согласно ADR-0005.

## Альтернативы

Создавать один ADR на сообщение пользователя. Границы такого документа зависят от формы разговора, а не от архитектуры.

## Последствия

- Решения можно независимо пересматривать и связывать ссылками.
- Агент отвечает за обоснованное разделение без дополнительных запросов о каждом документе.
- Количество ADR может увеличиться; связанные детали остаются в одной записи.
