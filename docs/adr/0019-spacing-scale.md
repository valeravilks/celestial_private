# ADR-0019: Единая шкала расстояний FSE-темы

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

После цветовой системы владелец поручил перенести ранее подготовленную модель расстояний. Документ задаёт согласованную шкалу; старая реализация отличается значениями токенов 50 и 60.

## Решение

Зарегистрировать девять пресетов `10–90` в `settings.spacing.spacingSizes` файла `wordpress/theme/theme.json`:

| Токен | Значение |
| --- | --- |
| 10 | `0.25rem` |
| 20 | `0.5rem` |
| 30 | `0.75rem` |
| 40 | `1rem` |
| 50 | `1.5rem` |
| 60 | `2rem` |
| 70 | `clamp(2.5rem, 5vw, 4rem)` |
| 80 | `clamp(4rem, 8vw, 6rem)` |
| 90 | `clamp(6rem, 10vw, 8rem)` |

Токены выражают расстояния, а не названия компонентов. Рекомендации применения, единицы и поведение fluid-значений хранить в `wordpress/theme/docs/spacing.md`. Пиксельные эквиваленты приблизительны и рассчитаны для корневого размера шрифта 16px.

Переносить значения из выбранного документа: для 50 — 1.5rem, для 60 — 2rem. Не переносить отличающиеся значения старого theme.json. Настройки ширины, корневых отступов и конкретных компонентов определять отдельно. Не добавлять новые значения без подтверждённой потребности.

## Альтернативы

Копировать шкалу старой реализации буквально. Это сохранило бы расхождение между документацией и кодом. Произвольные значения для каждого компонента не обеспечивают общего ритма.

## Последствия

- Фиксированные расстояния используют rem; крупные расстояния адаптируются в пределах clamp.
- Документация и реализация используют одну шкалу.
- Модель работает непосредственно в FSE-теме без сборки.
