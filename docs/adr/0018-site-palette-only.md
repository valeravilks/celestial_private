# ADR-0018: Выбор цветов только из палитры сайта

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

ADR-0017 определил 10 цветовых токенов сайта. Стандартная палитра WordPress и возможность вводить произвольные цвета позволяют редактору выходить за пределы этой системы.

## Решение

В `wordpress/theme/theme.json` установить:

```json
{
  "settings": {
    "color": {
      "defaultPalette": false,
      "custom": false
    }
  }
}
```

`defaultPalette: false` скрывает стандартную палитру WordPress, `custom: false` запрещает ввод произвольных цветов. В стандартных controls выбора цветов доступны только 10 пресетов из `settings.color.palette` темы.

Не отключать сами controls текста и фона: редактор должен иметь возможность выбирать цвет из палитры сайта. Градиенты, duotone и отдельные ограничения блоков не определяются этим решением.

## Альтернативы

Отключить только стандартную палитру. Это оставляет возможность вводить произвольные цвета и не выполняет требование владельца. Полностью скрыть controls текста и фона — лишает редактора выбора даже утверждённых цветов.

## Последствия

- Редактирование стандартных цветов ограничено утверждёнными пресетами сайта.
- Изменение палитры выполняется в исходниках темы.
- Ограничение UI не проверяет контраст выбранных сочетаний, не удаляет ранее сохранённые произвольные цвета и не запрещает ручное изменение кода или нестандартные controls сторонних блоков.
