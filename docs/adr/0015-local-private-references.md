# ADR-0015: Локальная папка приватных наработок

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

Владелец хочет хранить рядом с проектом наработки из других репозиториев и иногда явно поручать агенту найти в них ранее реализованное решение. Эти материалы не должны попадать в Git или передаваемые материалы.

## Решение

Создать в корне репозитория локальную папку `references/`. Исключить её целиком корневым правилом `/references/` в `.gitignore`.

Обращаться к содержимому только по явному запросу владельца в рамках конкретной задачи. Не включать папку в общий поиск исходников, Git-коммиты, архивы, клиентские поставки, публикации, загрузки и другие исходящие материалы. Не применять принудительное добавление игнорируемых файлов.

Если владелец поручает использовать конкретное решение, допускается адаптация необходимого кода в проекте. Это не означает разрешения переносить весь исходник или приватные данные. Без явного разрешения не копировать содержимое наработок в отслеживаемые файлы и внешние материалы.

Внутреннюю документацию о назначении папки хранить вне неё. Git не создаёт эту папку при клонировании; её нужно создать локально заново. `.gitignore` исключает файлы из обычного добавления в Git, но не управляет сторонними программами синхронизации или резервного копирования.

## Альтернативы

Хранить материалы в отслеживаемом каталоге. Это противоречит требованию приватности и создаёт риск передачи наработок вместе с историей репозитория.

## Последствия

- Примеры доступны локально без включения в историю проекта.
- Агент должен явно ограничивать поиск и состав передаваемых файлов.
- Папка требует отдельного локального хранения; Git не служит её резервной копией.
