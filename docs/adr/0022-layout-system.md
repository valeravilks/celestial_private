# ADR-0022: Общий layout FSE-темы

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

Владелец поручил перенести модель layout: общие ширины страницы и боковые отступы. Текущий минимальный каркас имел временные ширины 720px и 1100px, не закреплённые отдельным ADR.

## Решение

В settings.layout установить contentSize = 1200px и wideSize = 1600px. Обычный контент ограничивается contentSize; alignwide — wideSize; alignfull используется для фонов и секций на всю ширину.

В styles.spacing.padding задать боковые отступы через spacing-токен 40, верхний и нижний — 0px. Включить settings.useRootPaddingAwareAlignments, чтобы full-width и wide-блоки учитывали корневые отступы. Вертикальный ритм строить секциями и паттернами.

Длинному тексту разрешена более узкая локальная ширина для читаемости, без нового глобального токена. Не дублировать глобальные ширины в каждом блоке. Подробности хранить в wordpress/theme/docs/layout.md.

## Альтернативы

Сохранить временные размеры каркаса или задавать независимую ширину каждому компоненту. Владелец выбрал общую модель из подготовленного документа.

## Последствия

- Общий каркас страницы использует единую систему ширин и spacing.
- Layout не определяет конкретные секции и их внутренние отступы.
- Ширина 1200px является общей рамкой, а не обязательной шириной длинного текста.
