# ADR-0024: Правила стандартного блока Heading

- **Статус:** Заменено [ADR-0034](0034-pattern-led-editor.md)
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

Заменено 2026-10-13: общая политика ADR-0034 скрывает controls дизайна; исходный текст ниже сохранён для истории.

## Контекст

Владелец поручил перенести правила core/heading. Общая иерархия уже определена ADR-0021; теперь необходимо ограничить локальный выбор шрифта и размера, чтобы оформление заголовка следовало роли и не превращалось в набор случайных настроек.

## Решение

Общие стили заголовков хранить в styles.elements.heading, размеры и интервалы H1–H6 — в styles.elements.h1–h6 согласно ADR-0021. В settings.blocks.core/heading.typography установить fontFamilies: [] и fontSizes: []. Сохранить глобальные ограничения размера из ADR-0023.

HTML-уровень выбирать по структуре документа. Не создавать отдельные токены heading-h1 и подобные; при необходимости повторяющихся визуальных ролей использовать готовые block style variations, а не разовые inline-значения. Новые variations сейчас не регистрировать; uppercase и wide на H6 автоматически не назначать.

Сохранить цветовую модель ADR-0017 и выбор цвета из палитры по ADR-0018: contrast наследуется по умолчанию, controls цветов не скрываются. Примеры старого документа адаптировать к этим действующим решениям.

Причины и последствия хранить в этом ADR; инструкции настройки и применения — в самостоятельном wordpress/theme/docs/blocks/heading.md. Не дублировать стили общей типографики на уровне блока.

## Альтернативы

Оставить локальный выбор размера и семейства: он позволяет обходить стандартную иерархию. Копировать старые примеры без адаптации — расходится с действующей цветовой моделью.

## Последствия

- Заголовки используют типографику темы, controls семейства и размера скрыты.
- Отдельный визуальный сценарий потребует готового стиля, если он реально понадобится.
- Ограничения UI не очищают ранее сохранённые атрибуты блоков.
