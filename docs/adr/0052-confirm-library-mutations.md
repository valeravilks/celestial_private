# ADR-0052: Точное подтверждение изменений и удаления в библиотеке

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Автор решения:** Владелец проекта

## Контекст

Library хранит переиспользуемые результаты владельца. Запрос на изменение или удаление в рабочем проекте не должен приводить к потере библиотечных вариантов. Владелец требует видеть точный состав изменений до выполнения.

## Решение

Не удалять ничего из library/ без точного подтверждения владельца. Даже при прямом запросе удаления сначала показать точный список удаляемых файлов и каталогов, цель и последствия; дождаться подтверждения этого списка. Для каталога перечислять находящиеся в нём файлы, а не скрывать объём за названием папки.

Перед изменением существующих файлов library/ показать список конкретных файлов и суть изменений, затем дождаться подтверждения. Замена, перезапись, переименование и перемещение считаются изменениями; если операция удаляет старый путь, явно показать его. Общий запрос «обнови библиотеку» или «перенеси это в library» не заменяет подтверждения точного списка изменяемых существующих файлов.

Если владелец уже подтвердил конкретный список и операции, выполнять их без повторного запроса. При расширении списка или изменении операции согласовать дополнение до выполнения.

Создание новых записей по явному запросу владельца сохраняется по ADR-0045; если перенос затрагивает существующие библиотечные файлы, сначала согласовать их изменения. Read-only проверки и подготовка предложения разрешены без изменения файлов.

Запросы на удаление или изменение внутри wordpress/ относятся к рабочему проекту и не распространяются на library/. Обслуживание может выявлять расхождения, но исправления библиотечных файлов также проходят точное подтверждение. Эти правила не требуют дополнительного согласования обычных изменений внутренней документации вне library/.

## Альтернативы

Считать общий запрос достаточным для любого обновления библиотеки — скрывает от владельца объём перезаписи и удаления.

## Последствия

Владелец видит, какие сохранённые реализации затрагиваются. Работа с проектом продолжается независимо; перенос изменений в библиотеку требует отдельного согласования точного состава.
