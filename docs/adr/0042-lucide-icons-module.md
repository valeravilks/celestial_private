# ADR-0042: Lucide как встроенный модуль Celestial

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Автор решения:** Владелец проекта

## Контекст

Владелец выбрал Lucide и готовую реализацию Icon API, но хочет функциональность внутри Celestial вместо отдельного плагина.

## Решение

Хранить модуль в wordpress/plugin/includes/icons/index.php и подключать явным require_once из celestial.php. Регистрировать коллекцию lucide и имена lucide/<name> на init через стандартный API WordPress 7.1+. Использовать core/icon без собственного блока и JavaScript. Все глобальные функции имеют префикс celestial_; text domain celestial. При отсутствии API пропускать регистрацию и сообщать администратору, не ломая остальные модули. Не включать скрытые controls оформления; выбор иконки является выбором содержимого. Иконки остаются доступны при смене темы, пока Celestial активен.

## Альтернативы

Отдельный плагин иконок добавляет самостоятельную установку и активацию; собственный блок дублирует стандартную возможность WordPress.

## Последствия

Иконки являются штатной функциональностью Celestial. Для использования требуется WordPress 7.1+; при отключении плагина коллекция недоступна.
