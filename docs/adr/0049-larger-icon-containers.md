# ADR-0049: Увеличенные контейнеры вариантов Icon

- **Статус:** Заменено [ADR-0050](0050-balanced-icon-containers.md)
- **Дата:** 2026-10-14
- **Автор решения:** Владелец проекта

## Контекст

После ADR-0048 владелец попросил удвоить контейнеры Circle и Rounded square и подтвердил необходимость иконки цвета base на подложке primary.

## Решение

Сохранить базовую иконку 2rem цвета contrast без подложки. Для circle и rounded-square использовать контейнер 6rem вместо 3rem, рисунок 2rem цвета base, подложку primary. Circle — радиус 50%, rounded-square — 0.5rem. Явно задавать цвет base также SVG выбранных вариантов, а не полагаться только на наследование от контейнера.

Сохранить архитектуру ADR-0048: токены в theme.json, геометрия в assets/blocks/icon.css, регистрация в functions.php. Не менять коллекцию, controls и library. Стиль применяется только при соответствующем классе; обычные иконки не превращаются автоматически в варианты с подложкой.

## Альтернативы

Прежний контейнер 3rem оказался визуально недостаточным по оценке владельца. Увеличивать сам рисунок не запрошено.

## Последствия

При корневом шрифте 16px контейнер имеет размер 96px, рисунок 32px. Проверять занимаемое место в композиции. Сохранённые inline-параметры блока могут потребовать отдельной проверки.

## Связанные решения

Заменяет [ADR-0048](0048-icon-size-and-presentation-styles.md), сохраняя остальные его принципы. Сохраняет ADR-0034 и ADR-0045.
