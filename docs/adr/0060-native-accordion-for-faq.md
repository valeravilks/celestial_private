# ADR-0060: Штатный Accordion для раскрывающихся групп содержимого

- **Статус:** Принято
- **Дата:** 2026-10-15
- **Автор решения:** Владелец проекта

## Контекст

В FAQ тестового лендинга использовались отдельные core/details. Владелец выбрал штатный Accordion для таких групп вопросов и ответов.

## Решение

При создании и явной доработке FAQ и аналогичных групп раскрывающегося содержимого использовать `core/accordion` с `core/accordion-item`, `core/accordion-heading` и `core/accordion-panel`. Поведение и доступность опираются на штатную реализацию WordPress; не писать собственный переключатель и не заменять эту структуру набором Details или произвольным HTML.

Выбирать семантический уровень заголовков по окружению; после H2 секции использовать H3 вопросов. Сохранять кнопки, связь с панелями и клавиатурное управление Core. Оформление находится в теме: базовые свойства через theme.json, дополнительный CSS через wp_enqueue_block_style. Не добавлять плагин, сборку темы или новые controls.

На текущем шаге заменить четыре Details главной на один Accordion, сохранив тексты. Другие страницы и библиотеку автоматически не переписывать. Решение относится к группам раскрывающегося содержимого, а не запрещает семантический Details во всех возможных сценариях.

## Альтернативы

Отдельные Details — не соответствуют выбранному компоненту для FAQ; собственный JS или дополнительный плагин — лишний код при наличии Core.

## Последствия

Редактор и посетитель работают с нативным компонентом WordPress. Требуется версия WordPress с зарегистрированными блоками Accordion; при отсутствии поддержки остановиться и обсудить совместимость, не подменять механизм молча. Проверять открытие, закрытие, клавиатуру, узкий экран и валидацию в редакторе.

## Связанные решения
