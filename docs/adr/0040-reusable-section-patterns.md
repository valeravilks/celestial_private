# ADR-0040: Универсальные секции независимо от продукта

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Автор решения:** Владелец проекта

## Контекст

При создании страницы Celestial секционные паттерны были названы и заполнены под текущий продукт. Владелец уточнил: библиотека должна давать абстрактные композиции для разных проектов, с категориями по назначению, например Benefits.

## Решение

Библиотечные секции и переиспользуемые patterns описывают назначение и композицию, а не текущий продукт. Использовать нейтральные названия и подсказки для заполнения; группировать в редакторе по назначению: Hero, Benefits, Features, Process, FAQ, Contact и другие категории по необходимости.

Контент конкретного продукта хранить в установленной странице проекта или явно адаптированной реализации. Не переносить его в универсальные исходники библиотеки. Технический namespace celestial/ и префикс celestial_ не являются привязкой содержания к продукту и сохраняются.

Не задавать универсальным секциям обязательные ID якорей, ссылки на другие секции и ID объектов конкретного сайта. Проект назначает реальные адреса и уникальные якоря при адаптации. Нейтральные подсказки и начальные ссылки проверяются перед публикацией.

Шесть первых секций обобщить, сохранив заполненную страницу Celestial. Библиотечный Footer обобщить; выбранный футер проекта сохраняет его название.

## Альтернативы

Сохранять продуктовые тексты в библиотеке и заменять на каждом проекте. Это смешивает композицию с коммерческим предложением и затрудняет выбор секций.

## Последствия

Секции пригодны для разных проектов. После вставки требуется заполнить содержание и ссылки; обновления библиотечных файлов не меняют уже собранную страницу автоматически.
