# ADR-0059: Caption — вариация стиля Paragraph для небольших подписей

- **Статус:** Принято
- **Дата:** 2026-10-15
- **Автор решения:** Владелец проекта

## Контекст

Повторяющиеся подписи под фотографиями и пояснения в лендинге были оформлены локальным классом wardrobe-caption. Нужен понятный переиспользуемый стиль без новых токенов и отдельного блока.

## Решение

Использовать зарегистрированную style variation `caption` блока `core/paragraph` для небольших вспомогательных подписей. Стабильный класс — `is-style-caption`. Оформление задавать в `theme.json`: существующие токены sm, regular, normal и muted; обычный регистр и межбуквенный интервал, без декоративной точки Subtitle. На тёмных поверхностях явно выбирать читаемый цвет из палитры в оформлении композиции.

Caption не заменяет основной текст и не определяет отступы секции. Если подпись относится к изображению внутри Image, сохранять штатный `figcaption`; не заменять его Paragraph только ради вида. Эта запись не вводит новый тип блока и не меняет Subtitle.

На текущем шаге зарегистрировать стиль в теме, применить к существующим небольшим подписям главной и footer. Библиотеку не обновлять.

## Альтернативы

Локальные классы каждой секции — дублируют одну роль; отдельный кастомный блок — избыточен для обычного текста.

## Последствия

Подписи получают согласованное оформление на существующих токенах. В редакторе сохраняются общие ограничения controls. Изменение темы не требует сборки.

## Связанные решения

Дополняет ADR-0034, сохраняет ADR-0013, ADR-0028, ADR-0045 и ADR-0052. Действующие ADR не заменяются.
