# ADR-0035: Шаблоны состоят только из template parts

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

Владелец хочет разделить сборку шаблонов страницы и разработку их частей. Текущий index.html содержит Group, Query и другие блоки непосредственно в шаблоне.

## Решение

Файлы wordpress/theme/templates/*.html должны содержать только ссылки на core/template-part. Не размещать там HTML-разметку, Group, Query, Post Content, прямые ссылки на паттерны и другие блоки. Пробелы и переносы строк допустимы.

Разметку, layout-обёртки и блоки помещать в wordpress/theme/parts/*.html. Шаблон выбирает последовательность частей, а части отвечают за содержимое и композицию. Части при необходимости могут включать другие части или паттерны; избегать циклических ссылок.

Каждый slug из шаблона должен разрешаться в существующий файл части. При создании и проверке шаблонов проверять типы блоков, отсутствие посторонней разметки и наличие частей.

Перенести текущую разметку index.html без изменений в parts/main-index.html; index.html заменить одной ссылкой на эту часть. Состав будущих частей header/footer/page/404 определить отдельно; это решение не требует создавать их сейчас.

## Альтернативы

Хранить композицию непосредственно в шаблонах, как в текущем каркасе. Это допустимо для WordPress, но владелец выбирает более строгую границу между шаблонами и частями.

## Последствия

- Шаблоны становятся краткими точками сборки из частей.
- Все layout-обёртки также должны находиться в parts.
- Переиспользование частей требует явного состава и проверки зависимостей.
- Правило относится к исходникам; пользовательские версии шаблонов в базе данных могут отличаться и требуют отдельной политики.
