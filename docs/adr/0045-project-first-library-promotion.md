# ADR-0045: Разработка в проекте, перенос в библиотеку по запросу

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Автор решения:** Владелец проекта

## Контекст

Агент создавал и обновлял проектные элементы одновременно в wordpress/ и library/. Владелец уточнил workflow: сначала работа над элементом в реальном проекте, затем отдельный явно запрошенный перенос результата в библиотеку.

## Решение

Новые блоки, style variations, секции и их изменения сначала разрабатывать, адаптировать и проверять внутри wordpress/. Не создавать и не обновлять соответствующие реализации в library/ автоматически, даже если элемент пригоден для повторного использования.

Переносить результат из wordpress/ в library/ только после явного запроса владельца, например «перенеси это в library». При переносе выделять необходимые файлы и зависимости, обобщать продуктовый контент по ADR-0040, описывать назначение, ограничения, использование и фактически выполненные проверки. Библиотечный статус не считать проверенным без достаточного подтверждения.

Разрешённое использование уже существующей library/ для выбора элементов сохраняется по ADR-0037–0039. Правки выбранной реализации в проекте не обновляют библиотечный оригинал автоматически. Источник истины о текущем сайте — wordpress/; библиотека хранит отдельно сохранённые переиспользуемые результаты.

Существующие библиотечные записи не удалять и не синхронизировать задним числом. Пример владельца с точкой цвета primary у Subtitle объясняет workflow и сам по себе не является поручением изменить стиль.

## Альтернативы

Одновременно поддерживать проект и библиотеку при каждом изменении. Это закрепляет промежуточные варианты до оценки владельцем и смешивает эксперимент с сохранением переиспользуемого результата.

## Последствия

Итерации выполняются в работающем сайте. Наполнение библиотеки становится отдельным осознанным шагом; проект и ранее сохранённая библиотечная версия могут различаться.

## Связанные решения

Дополняет [ADR-0037](0037-internal-design-library.md) и [ADR-0039](0039-project-source-of-truth.md), сохраняя структуру библиотеки и границу передачи. Сохраняет [ADR-0040](0040-reusable-section-patterns.md). Действующие ADR не заменяются: они определяли хранение и использование, но не требовали автоматического пополнения библиотеки.
