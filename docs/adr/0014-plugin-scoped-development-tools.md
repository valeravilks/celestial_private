# ADR-0014: Инструменты плагина вместо npm-проекта в корне wordpress

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

После перехода на глобальный wp-env в корне `wordpress/` остались `package.json`, `package-lock.json` и `.nvmrc`, хотя локальных npm-зависимостей нет. Владелец уточнил, что будущие npm-инструменты и конфигурация Node.js будут находиться внутри плагина; метод их организации будет определён позднее.

## Решение

Удалить `wordpress/package.json`, `wordpress/package-lock.json` и `wordpress/.nvmrc`. Запускать локальное окружение прямыми командами глобального wp-env из `wordpress/`, сохраняя `.wp-env.json` и автоматическую активацию темы.

Устанавливать `@wordpress/env` глобально в совместимом окружении Node.js. Смена окружения Node.js требует проверки наличия глобального инструмента. Корневые npm-скрипты и установка локальных зависимостей для запуска WordPress не нужны.

Будущие `package.json`, lock-файл, `.nvmrc` и зависимости плагина размещать внутри `wordpress/plugin/`. Сейчас их не создавать: версии, команды, зависимости и способ сборки плагина будут определены отдельно. Тема продолжает работать без сборки согласно ADR-0013.

Сохранить самостоятельный проект в `wordpress/` и его границу передачи клиенту. ADR, описание архитектуры, правила агента и приватные заметки остаются вне этого каталога и не входят в передачу, как и история внутреннего репозитория. База данных и медиафайлы требуют отдельной миграции.

## Альтернативы

Сохранить npm-проект в корне `wordpress/` только ради команд запуска глобального инструмента. Владелец предпочитает прямые команды wp-env и размещение будущих npm-инструментов в плагине.

## Последствия

- Корень WordPress-проекта содержит конфигурацию окружения и компоненты, без npm-проекта и `.nvmrc`.
- Запуск выполняется через `wp-env start`, остановка — через `wp-env stop`.
- Инструменты плагина будут определяться независимо от темы и глобального wp-env.
- Путь `.wp-env.json` сохраняется, поэтому удаление npm-файлов не создаёт нового окружения.
