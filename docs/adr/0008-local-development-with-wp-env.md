# ADR-0008: Локальная разработка через wp-env

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

Для разработки WordPress-темы и плагина необходимо локальное окружение. В ADR-0004 выбор инструмента был оставлен для последующего решения.

## Решение

Использовать пакет `@wordpress/env` и его инструмент `wp-env` для локального запуска WordPress и подключения разрабатываемых темы и плагина.

На текущем этапе зафиксировать выбор. Установку пакета, конфигурацию окружения, версии и команды запуска выполнить отдельно; сейчас окружение не создаётся.

## Альтернативы

Другие локальные окружения не выбирались и подробно не сравнивались. Инструмент выбран владельцем проекта.

## Последствия

- Локальное окружение будет запускаться через wp-env.
- Тему и плагин необходимо подключить к окружению при его настройке.
- Выбор локального окружения можно пересмотреть независимо от разделения исходников на тему и плагин.
