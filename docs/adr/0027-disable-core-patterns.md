# ADR-0027: Отключение стандартных паттернов WordPress Core

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

Владелец не использует стандартные паттерны WordPress Core и поручил перенести их отключение из ранее разработанной темы. Готовые композиции проекта должны определяться его собственной системой оформления.

## Решение

В `wordpress/theme/functions.php` вызвать `remove_theme_support( 'core-block-patterns' )` через хук `after_setup_theme`, как в выбранном исходнике. Это отключает регистрацию встроенных паттернов WordPress Core для активной темы.

Не удалять пользовательские паттерны, паттерны проекта или регистрации сторонних плагинов. Доступ к удалённому каталогу паттернов WordPress.org этим решением отдельно не отключается. Уже вставленное в страницы содержимое сохраняется.

Описать правило в документации темы. Код относится к настройке представления и не требует сборки.

## Альтернативы

Сохранять стандартные паттерны или удалять все зарегистрированные паттерны без различия происхождения. Первый вариант не соответствует процессу владельца, второй затрагивает собственные и пользовательские композиции сверх запроса.

## Последствия

- Встроенные паттерны Core не регистрируются при активной теме Celestial.
- Собственные паттерны остаются доступным способом создания композиций проекта.
- Отключение не удаляет ранее созданное содержимое.
