# ADR-0043: Готовые ресурсы иконок без локальной генерации

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Автор решения:** Владелец проекта

## Контекст

Владелец разрешил перенос только готового dist IconsPlugin, исключив разработку и сборку исходного проекта.

## Решение

Хранить готовые SVG, manifest.php, library.json и Lucide-LICENSE внутри includes/icons, в Git и клиентской поставке. Перенести набор lucide-static 1.55.0: 2141 иконка, включая алиасы. Готовую геометрию сохранять без изменений. Не переносить ZIP, отдельный plugin header, исходники генерации, npm-зависимости, тестовую инфраструктуру и служебные файлы. Набор не является генерируемым build/ Celestial. Обновлять явно из нового проверенного готового релиза с сохранением лицензии и проверкой идентификаторов. Автоматическое обновление и обращения к CDN не вводить.

## Альтернативы

Генерация внутри Celestial потребовала бы дополнительных инструментов и исходников, которые владелец явно исключил.

## Последствия

Поставка включает около 8.7 МБ готовых ресурсов. Обновление выполняется отдельно от сборки редактора и custom blocks.
