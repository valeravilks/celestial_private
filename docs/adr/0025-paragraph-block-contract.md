# ADR-0025: Правила стандартного блока Paragraph

- **Статус:** Заменено [ADR-0034](0034-pattern-led-editor.md)
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

Заменено 2026-10-13: общая политика ADR-0034 скрывает controls дизайна; исходный текст ниже сохранён для истории.

## Контекст

Владелец поручил перенести правила core/paragraph. Базовый текст уже настроен общей типографикой; локальный выбор семейства и размера должен уступить место согласованным текстовым ролям. Старый документ предлагает глобальный color.text: false, что противоречит сохранению выбора палитры в ADR-0018.

## Решение

Paragraph наследует styles.typography: Ubuntu, md, regular и normal согласно ADR-0021. Не дублировать базовую типографику в styles.blocks.core/paragraph.

В settings.blocks.core/paragraph.typography установить fontFamilies: [] и fontSizes: [], сохранив глобальные ограничения ADR-0023. Не заменять абзацы заголовками ради размера и не задавать случайные размеры или веса в паттернах.

Сохранить ADR-0018: controls цветов доступны из палитры сайта, color.text: false не устанавливать. По умолчанию текст наследует contrast. Для вторичного и вводного текста при подтверждённой потребности создавать готовые block style variations с существующими токенами; lead и muted сейчас не регистрировать.

Причины хранить в ADR, настройку и использование — в wordpress/theme/docs/blocks/paragraph.md. Это документация клиентского компонента без зависимости от приватного хранилища.

## Альтернативы

Оставить произвольный локальный выбор типографики. Он позволяет нарушать общие роли. Глобально скрыть цвет по старому документу — противоречит действующему решению и не требуется для ограничения типографики.

## Последствия

- Абзацы используют базовую типографику, controls семейства и размера скрыты.
- Повторяющиеся альтернативные текстовые роли требуют готового стиля, а не нового токена компонента.
- Ограничения UI не очищают ранее сохранённые атрибуты блоков.
