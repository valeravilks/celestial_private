# ADR-0029: Префикс celestial_ для глобальных PHP-функций

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

Тема и плагин выполняются вместе с WordPress и сторонними расширениями. Их глобальные функции используют общее пространство имён PHP. Уже применяемый префикс нужно закрепить как проверяемое правило проекта.

## Решение

Все собственные именованные глобальные PHP-функции темы и плагина должны начинаться с `celestial_` в нижнем регистре. После префикса использовать понятное имя в snake_case, например `celestial_disable_core_patterns` или `celestial_theme_register_block_styles`.

Имена должны быть уникальны также между темой и плагином: один общий префикс не предотвращает повторное объявление внутри проекта. При необходимости уточнять принадлежность через `celestial_theme_` или `celestial_plugin_` и дальнейшее назначение функции.

При добавлении, переносе и проверке кода проверять префикс, уникальность имени и ссылки на функцию, включая callbacks хуков. Не маскировать конфликт собственных имён через function_exists вместо корректного именования.

Правило относится к собственным глобальным PHP-функциям. Оно не требует переименования методов классов, анонимных функций или функций WordPress и сторонних библиотек. Архитектуру классов и пространств имён определять отдельно, если потребуется.

## Альтернативы

Использовать короткие имена без префикса: увеличивает вероятность конфликта с другими расширениями. Перевести текущие функции в namespace: отдельный архитектурный выбор, который сейчас не требуется.

## Последствия

- У глобальных функций проекта есть узнаваемый префикс.
- Ревью должно проверять как префикс, так и отсутствие повторяющихся имён.
- Существующие функции соответствуют правилу и не требуют переименования.
