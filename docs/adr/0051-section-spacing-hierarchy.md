# ADR-0051: Смысловая группировка и иерархия расстояний в секциях

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Автор решения:** Владелец проекта

## Контекст

ADR-0046 объединил Subtitle и заголовок. Владелец уточнил общий принцип дизайна: основной контент тоже образует отдельную группу; расстояния должны показывать смысловую иерархию, сохраняя цельность секции.

## Решение

В новых и явно дорабатываемых секциях с вводным блоком использовать корневую core/group секции, содержащую отдельную вводную Group (Subtitle и заголовок) и отдельную Group основного содержимого (колонки, карточки или другие блоки).

Соблюдать соотношение: gap между Subtitle и заголовком < gap между вводной Group и Group содержимого ≤ вертикальный padding секции. При разных верхнем и нижнем padding межгрупповой gap не должен превышать меньший из них. Если padding равен нулю, положительный gap не соответствует этому принципу: композицию нужно пересмотреть явно, а не молча игнорировать правило.

Конкретные значения выбирать из токенов расстояний темы под композицию. При fluid-значениях проверять соотношение на применяемых ширинах. Внутренние интервалы основной Group определять отдельно по её содержимому; не обнулять их глобально и не требовать одинакового gap у всех вложенных блоков.

Например, spacing 20 внутри вводной Group, spacing 50 между группами и spacing 70 для вертикального padding соответствуют иерархии. Это пример, не обязательные размеры для каждой секции.

Применять к новым и явно адаптируемым секциям. Существующие patterns и library сейчас не изменять; расхождения выявлять при отдельно порученном обслуживании по ADR-0047. Перенос проектных изменений в библиотеку выполнять по ADR-0045. Controls дизайна редактора не включать.

## Альтернативы

Размещать все элементы на одном уровне с одинаковыми интервалами — ослабляет смысловую группировку. Задавать единственный фиксированный набор расстояний всем секциям — не учитывает различия содержимого.

## Последствия

Вводный блок читается как единое целое, основной контент отделён от него, а межгрупповой промежуток не превышает внешние поля секции. Проверка композиции должна учитывать вложенность и фактические расстояния, включая fluid-токены.
