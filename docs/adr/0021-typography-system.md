# ADR-0021: Типографическая система FSE-темы

- **Статус:** Заменено [ADR-0055](0055-distinct-heading-scale.md)
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

Владелец поручил перенести модель типографики из подготовленного документа. Старый theme.json использует другую шкалу размеров и не реализует заявленный line-height H5–H6.

## Решение

Использовать локальные Ubuntu и Roboto в обычном начертании, весах 400 и 700. Семейства и файлы fontFace регистрировать в settings.typography.fontFamilies. Базовое семейство — Ubuntu; Roboto доступен для отдельных задач.

Зарегистрировать размеры из выбранного документа: sm = 0.875rem, md = 1rem, lg = 1.25rem, xl = 1.5rem, 2xl = 1.75rem, 3xl = 2rem, 4xl = 2.5rem. Значения старого JSON не переносить. Не менять размер html ради пересчёта rem.

В settings.custom хранить независимые токены: fontWeight regular/bold = 400/700; lineHeight tight/snug/normal/relaxed = 1.2/1.4/1.6/1.75; letterSpacing normal/wide = 0/0.08em.

Базовый текст использует Ubuntu, md, regular и normal. Заголовки H1–H6 используют соответственно 4xl, 3xl, 2xl, xl, lg, md и вес bold. H1–H4 получают tight, H5–H6 — snug. HTML-уровень определяется структурой документа, а не желаемым размером. Wide и uppercase автоматически на H6 не назначать: это отдельное применение при необходимости.

Цвет текста сохраняется по ADR-0017: contrast на фоне base. Подробные правила хранить в wordpress/theme/docs/typography.md. Тема использует готовые файлы без сборки.

## Альтернативы

Перенести старый JSON без сверки: он не совпадает с выбранной моделью. Подключать шрифты с внешнего сервиса — создаёт дополнительную зависимость загрузки сайта.

## Последствия

- Документация и рабочие значения типографики согласованы.
- Локальные шрифты передаются вместе с темой; дополнительные начертания требуют соответствующих файлов.
- Семантика заголовков отделена от визуального размера.
