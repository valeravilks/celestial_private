# ADR-0004: WordPress, Gutenberg и FSE-тема как основа разработки

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

Для системы разработки сайтов необходимо определить технологическую основу будущего проекта. Согласно ADR-0001, дальнейшая архитектура формируется постепенно.

## Решение

Разрабатывать сайты на WordPress, используя редактор Gutenberg и блочную тему с поддержкой Full Site Editing (FSE).

Выделить каталог `wordpress/` для хранения будущего WordPress-проекта. На этом этапе создать каталог с описанием назначения. Выбор конкретной темы, структура исходников, локальное окружение, версии и инструменты сборки будут определяться последующими решениями.

## Альтернативы

Другие платформы, редакторы и типы тем на момент принятия решения не обсуждались. Основа выбрана владельцем проекта.

## Последствия

- Дальнейшие архитектурные решения принимаются с учётом WordPress, Gutenberg и FSE-темы.
- Проект будет опираться на блоки и возможности блочной темы.
- Для исходников будущего проекта выделен отдельный каталог в репозитории.
