# ADR-0053: Редактирование только содержимого информационной секции

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Автор решения:** Владелец проекта

## Контекст

При редактировании вставленного паттерна Enter создаёт новый Paragraph. Скрытие controls дизайна не блокирует изменение структуры. Владелец поручил применить content-only блокировку к текущему паттерну с шестью иконками.

## Решение

Установить templateLock contentOnly на корневой Group wordpress/theme/patterns/information-six-items.php и соответствующей секции главной страницы. В обычном режиме разрешено редактирование содержимого существующих блоков, а добавление, удаление и перестановка вложенных блоков ограничены стандартным механизмом WordPress. Не блокировать всю страницу: другие секции остаются отдельными элементами композиции.

Не менять тексты, иконки и интервалы. Не изменять другие patterns и library. Уже вставленные экземпляры на других страницах не обновляются автоматически; их нужно адаптировать отдельно. Блокировка не является ограничением прав администратора или доступа к редактору кода; клиентские права и возможность перехода в режим изменения структуры требуют отдельного решения.

## Альтернативы

Только скрыть controls дизайна — не препятствует созданию новых Paragraph. Блокировать всю страницу — ограничивает сборку из секций шире текущего запроса.

## Последствия

Файловый pattern задаёт contentOnly при новых вставках. Существующий экземпляр главной обновлён отдельно. Поведение Enter, вставки и выбора иконки нужно проверить в визуальном редакторе; сохранение атрибута само по себе не подтверждает все UI-сценарии.

## Связанные решения

Дополняет ADR-0034 в части структуры только выбранной секции. Сохраняет ADR-0045, ADR-0051 и ADR-0052. Действующие ADR не заменяются.
