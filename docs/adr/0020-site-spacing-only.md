# ADR-0020: Выбор расстояний только из шкалы сайта

- **Статус:** Заменено [ADR-0034](0034-pattern-led-editor.md)
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

Заменено 2026-10-13: общая политика ADR-0034 скрывает controls дизайна; исходный текст ниже сохранён для истории.

## Контекст

Шкала ADR-0019 должна оставаться единственным источником расстояний в стандартных controls редактора. Владелец поручил ограничить выбор аналогично палитре цветов.

## Решение

В `settings.spacing` файла `wordpress/theme/theme.json` установить `defaultSpacingSizes: false` и `customSpacingSize: false`. Стандартная шкала WordPress отключена, ввод произвольных расстояний запрещён. Выбор ограничен девятью пресетами темы.

Включить `blockGap: true`, чтобы поддерживающие его блоки предоставляли выбор расстояния между дочерними блоками из принятой шкалы. Доступность padding и margin для отдельных блоков определять отдельно; не переносить сейчас корневые отступы и настройки layout старой темы.

## Альтернативы

Зарегистрировать только пресеты без ограничений. Это оставляет дополнительные стандартные значения или произвольный ввод. Полностью отключить spacing-controls — лишает пользователя выбора утверждённых расстояний.

## Последствия

- Стандартные spacing-controls используют принятую шкалу.
- Ограничение UI не удаляет ранее сохранённые значения и не управляет ручным кодом или нестандартными controls сторонних блоков.
- Доступность конкретных controls и значения отступов компонентов остаются отдельными решениями.
