# ADR-0013: Основная FSE-тема без сборки

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

ADR-0004 определил FSE как основу темы, а ADR-0009 разделил оформление и сохраняемую функциональность. Владелец уточнил свой процесс: тема должна содержать только необходимое для FSE-темы и работать непосредственно из исходных файлов, без собственной сборки.

## Решение

Использовать Celestial в `wordpress/theme/` как основную тему проекта по умолчанию: самостоятельную блочную тему с поддержкой Full Site Editing. Это собственная тема проекта, а не стандартная тема из поставки WordPress.

Тема отвечает за внешнее представление: блочные шаблоны и их части, `theme.json`, паттерны оформления, готовые стили и ресурсы. Добавлять только файлы и код, необходимые для этих задач. Настройки и PHP-код, если потребуются, должны обслуживать исключительно представление и работу темы.

У темы нет собственного процесса сборки. Не добавлять в неё инструменты компиляции и bundling, npm-зависимости сборки, каталоги с генерируемыми результатами `build/` или `dist/`. Файлы темы должны быть пригодны для использования WordPress напрямую, без предварительной сборки, в том числе запускаемой из корня проекта.

Типы записей, интеграции, бизнес-логика и функциональность, сохраняемая при смене темы, относятся к плагину согласно ADR-0009. Способ разработки и сборки плагина этим решением не определяется.

Поддерживать самостоятельное описание роли и ограничений темы в `wordpress/theme/README.md`. В локальном окружении Celestial активируется по умолчанию существующим afterStart-хуком wp-env.

## Альтернативы

Тема со сборкой ресурсов. Владелец выбрал прямую разработку файлов FSE-темы, чтобы не вводить дополнительный этап подготовки темы.

## Последствия

- Тема запускается из исходников и передаётся без этапа сборки.
- Новые инструменты и функциональность не должны размывать границу ответственности темы.
- Возможности, требующие компиляции исходников темы, потребуют пересмотра этого ADR до реализации.
- Для плагина можно отдельно выбирать инструменты, сохраняя границу компонентов.
