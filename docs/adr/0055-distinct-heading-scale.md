# ADR-0055: Более выраженная шкала заголовков

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Автор решения:** Владелец проекта

## Контекст

Владелец заметил, что H2 32px и H3 28px визуально сливаются, и разрешил попробовать новую шкалу для оценки на сайте.

## Решение

Сохранить семь slugs размеров и mapping H1–H6 на 4xl, 3xl, 2xl, xl, lg, md. Новые значения: sm 0.875rem, md 1rem, lg 1.125rem, xl 1.25rem, 2xl 1.5rem, 3xl 2.25rem, 4xl 3rem. При корневом шрифте 16px заголовки соответственно 48, 36, 24, 20, 18 и 16px. Базовый Paragraph и Subtitle sm сохраняют размеры.

Это первая рабочая итерация для визуальной оценки владельцем. Размеры глобальных токенов меняются также в других местах, которые их используют; не переопределять только один паттерн. Не вводить fluid-масштабирование этим шагом.

Сохранить остальные правила ADR-0021: локальные Ubuntu/Roboto 400/700, токены веса и интервалов, основной текст Ubuntu/md/regular/normal, заголовки bold, H1–H4 tight и H5–H6 snug. HTML-уровень определяется структурой документа, не желаемым размером. Размер html ради пересчёта rem не менять. Controls дизайна остаются скрытыми; library не обновлять.

## Альтернативы

Сохранить разницу H2/H3 4px — она не устраивает владельца. Локально уменьшить только карточки — не проверяет общую шкалу.

## Последствия

H2 заметнее отличается от H3; H1 становится крупнее. Проверять длинные заголовки и узкие экраны. При неудовлетворительной оценке пересмотреть шкалу новой итерацией, сохраняя историю.

## Связанные решения

Заменяет [ADR-0021](0021-typography-system.md) с сохранением перечисленных принципов. Сохраняет ADR-0034 и ADR-0045.
