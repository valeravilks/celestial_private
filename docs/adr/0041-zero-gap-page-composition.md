# ADR-0041: Нулевой gap общей композиции страницы

- **Статус:** Принято
- **Дата:** 2026-10-14
- **Автор решения:** Владелец проекта

## Контекст

Стандартный межблочный gap создаёт видимые полосы между крупными секциями с разным фоном. Владелец хочет общую Group в шаблонах с нулевым gap. Секции внутри Post Content находятся на отдельном уровне и требуют своей композиционной обёртки.

## Решение

Во всех templates/*.html использовать общую core/group с layout default и style.spacing.blockGap = "0". Внутри размещать template parts и допустимые композиционные Group по ADR-0036.

Когда содержимое страницы состоит из полноширинных секций, объединять их общей Group с таким же нулевым gap. Применить это к текущей главной странице и исходному набору её блоков. Не обнулять gap глобально у всех блоков: расстояния внутри секций и текстовых композиций сохраняются. Внешние интервалы при необходимости задаются явно самой секцией.

Не включать controls gap в редакторе и не менять глобальную политику ADR-0034. Нулевой gap задаётся в коде композиции.

## Альтернативы

Обнулить gap только в шаблоне — не устраняет промежутки между секциями в Post Content. Обнулить все интервалы глобально — нарушает внутреннюю композицию секций.

## Последствия

Header, Content и Footer, а также соседние секции главной прилегают друг к другу. При создании новых страниц из секций нужно сохранять общую обёртку. Существующие страницы и пользовательские шаблоны в базе проверяются отдельно; они не перезаписываются автоматически.
