# ADR-0017: Семантическая цветовая палитра FSE-темы

- **Статус:** Принято
- **Дата:** 2026-10-13
- **Автор решения:** Владелец проекта

## Контекст

Для постепенного переноса дизайн-системы требуется сначала определить устойчивые роли цветов. Владелец выбрал ранее подготовленную модель цветов и поручил самостоятельно подобрать конкретные стартовые значения.

## Решение

Использовать 10 цветовых токенов в `settings.color.palette` файла `wordpress/theme/theme.json`:

- Брендовые: `primary`, `secondary`, `accent`.
- Основные: `base` — основной фон; `contrast` — основной текст.
- Поверхность: `surface`.
- Вторичный текст: `muted`.
- Состояния: `success`, `warning`, `error`.

Сохранять эти роли независимо от конкретных цветов клиента. Стартовую палитру подобрать для текущей темы; точные значения и правила применения хранить в самостоятельной документации `wordpress/theme/docs/colors.md`, а рабочие значения — в `theme.json`. Глобальный фон использует `base`, текст — `contrast`.

Проверять контраст: обычный текст не ниже 4.5:1, крупный текст не ниже 3:1; значимые нетекстовые элементы — не ниже 3:1 там, где применимо. Обязательные пары: `base/contrast`, `base/muted`, `surface/contrast`, `surface/muted`, `contrast/base`. Брендовые цвета проверять с выбранным foreground отдельно. Наличие токенов в палитре не разрешает произвольное сочетание любых двух цветов.

Не добавлять отдельные цветовые токены компонентов и `border`; цвет границы выбирать из существующей палитры. `surface-alt` и градиенты в эту версию системы не включать. Ограничения controls редактора определить отдельно.

## Альтернативы

Перенести значения старой темы вместе с обратным использованием `base` и `contrast`. Это расходится с выбранной моделью ролей. В текущем проекте роли закрепляются по документу цветов, а значения подобраны заново по поручению владельца.

## Последствия

- Палитра задаёт общие роли и переиспользуется в оформлении блоков и секций.
- Адаптация к бренду клиента требует повторной проверки контраста.
- При переносе остальных материалов дизайн-системы их примеры нужно согласовать с `base` как фоном и `contrast` как текстом.
- Тема остаётся без сборки; приватное хранилище наработок не включается в Git или клиентский проект.
