# Footer: Copyright

- **Статус:** Черновик
- **Pattern slug:** celestial/footer-copyright

## Назначение

Минимальный футер с названием проекта и годом. Без меню и дополнительных секций.

## Состав

Group full-width с constrained layout и Paragraph. Ширина содержимого определяется contentSize темы. Семантический footer задаётся при подключении template part.

## Содержимое

Начальный текст: «© Название компании 2026». Название и год — обычный редактируемый текст; год не обновляется автоматически. При переносе заменить на данные проекта.

## Зависимости

Стандартные блоки Group и Paragraph, spacing 50, contentSize и root padding темы. Дополнительные стили и PHP-функции не требуются.

## Перенос и адаптация

Перенести pattern.php в patterns/footer-copyright.php темы. Подключить celestial/footer-copyright из parts/footer.html через core/pattern. Тема работает без library. Это обычный файловый pattern; общую часть для шаблонов предоставляет footer template part, отдельно вставленные экземпляры не синхронизируются.

## Проверки

2026-10-14: проверен HTTP-рендер подключённого паттерна внутри footer, текст copyright и constrained layout. Мобильная ширина, длинный текст и редактор визуально ещё не проверены; статус — «Черновик».
