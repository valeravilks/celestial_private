# Celestial: состав проекта

- **Статус:** Черновик
- **Pattern slug:** celestial/product-deliverables

## Назначение

Секция продуктовой страницы Celestial, якорь `included`. Текст — начальное предложение для обсуждения, без вымышленных кейсов, отзывов, цен и гарантий.

## Состав

Стандартные блоки WordPress в Group section с constrained layout. Заголовок секции H2; подпункты H3.

## Содержимое

Тексты и ссылки редактируются после вставки. Уточнить предложение с владельцем перед публикацией. Сохранять смысл и краткость заголовков.

## Зависимости

Палитра base/contrast/primary/surface, spacing 70, contentSize и root padding. Без custom blocks, CSS, style variations и внешних ресурсов. Якоря должны быть уникальны на странице.

## Перенос и адаптация

Перенести pattern.php в patterns/product-deliverables.php темы и вставить через редактор. Паттерн обычный, несинхронизированный: вставка создаёт редактируемые блоки. Изменения файла не обновляют ранее вставленный контент автоматически. Приватных зависимостей нет.
