# Features: три направления с иконками

- **Статус:** Черновик
- **Pattern slug:** celestial/information-three-items
- **Категория:** features

## Назначение

Три направления продукта или услуги. Композиция сохранена по запросу владельца из секции «Что мы создаём» мебельного теста. Тексты обобщены для разных проектов; бренд, фиксированные якоря и ID сайта отсутствуют.

## Состав

Корневая Group section с фоном surface и текстом contrast содержит вводную Group (Subtitle + H2, gap 20) и Group контента (Columns из трёх Column). В каждой колонке core/icon, H3 и Paragraph. Межгрупповой gap 60, вертикальный padding 70; 20 < 60 ≤ 70 соответствует ADR-0051. На узкой ширине используются стандартные складывающиеся Columns.

## Содержимое

Заполнить Subtitle, основной заголовок и три пункта. Иконки сохранены из одобренного мебельного примера: lucide/cooking-pot — кухни, lucide/door-open — шкафы и гардеробные, lucide/layers — комплексные системы мебели. Нейтральные подписи пунктов не задают новый смысл этим иконкам: при другой тематике подобрать подходящие Lucide из установленного manifest по ADR-0044. Иконки декоративные, смысл раскрывается текстом.

## Зависимости

Стандартные Group, Paragraph, Heading, Columns, Column и Icon; коллекция Lucide из модуля Celestial. Стиль paragraph/subtitle (в исходном проекте dot), базовое оформление Icon 2rem/contrast без подложек. Токены surface/contrast, spacing 20/50/60/70, contentSize и root padding; Subtitle dot дополнительно использует muted/primary и CSS. Категория features должна быть зарегистрирована.

## Перенос и адаптация

Перенести pattern.php в patterns/information-three-items.php темы, установить зависимости Subtitle и Icon. Вставить из Features и заполнить содержание. Изображений и дополнительных собственных CSS-файлов секции нет. Экземпляры обычного паттерна независимы и не обновляются автоматически. Сайт не зависит от library.

Корневая Group сохраняет экспериментальный templateLock contentOnly исходного проекта. Он предназначен для редактирования содержимого, но не считается подтверждением полной защиты структуры; проверить Enter, вставку и выбор иконок в целевом редакторе по ADR-0054.

## Проверки

2026-10-15: владелец визуально одобрил исходную секцию на сайте. При сохранении проверены три колонки, три существующих идентификатора Lucide, группировка, интервалы и отсутствие продуктового бренда/якорей. В мебельном тесте проверялись серверный рендер и отсутствие переполнения при фактической узкой ширине 582px. Полные проверки редактора, точных мобильных размеров и длинного контента не завершены; статус «Черновик».
