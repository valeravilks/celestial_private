# Hero: заголовок и две кнопки

- **Статус:** Черновик
- **Pattern slug:** celestial/hero-intro
- **Категория:** hero

## Назначение

Переиспользуемая секция для разных продуктов и проектов. Название описывает назначение и композицию, а не конкретный бренд. celestial в slug — технический namespace библиотеки, не содержание продукта.

## Состав

Стандартные блоки WordPress внутри Group section с constrained layout. Hero содержит H1 и две кнопки. При повторном использовании на странице изменить уровень заголовка.

## Содержимое

Нейтральные подсказки для заполнения. Заменить тексты данными проекта и проверить все ссылки. Кнопки первоначально ведут на /; перед использованием назначить целевые адреса. Нет заранее заданных якорей: при необходимости назначить уникальный anchor в проекте.

## Зависимости

Core-блоки, токены base/contrast/primary/surface, spacing 70, contentSize и root padding. Для категории hero нужна регистрация через register_block_pattern_category в теме. Дополнительные ресурсы и private runtime-зависимости отсутствуют.

## Перенос и адаптация

Перенести pattern.php в patterns/hero-intro.php темы, зарегистрировать категорию и вставить через редактор. Заполненный контент хранится в странице проекта. Это обычный несинхронизированный pattern: обновления файла не перезаписывают вставленные экземпляры.

## Проверки

Предыдущая композиция проверена на продуктовой странице. 2026-10-14: после обобщения проверены регистрация категорий и паттернов, рендер, отсутствие продуктового контента и сохранность заполненной страницы. Редактор и длинный контент ещё требуют проверки; статус «Черновик».
