# Content: два изображения с описаниями

- **Статус:** Черновик
- **Pattern slug:** celestial/content-two-images
- **Категория:** features

## Назначение

Контентная секция для двух визуальных направлений или примеров с короткими описаниями. Сохранена по запросу владельца из мебельного теста; композиция визуально одобрена. Примечания об изображениях не выводятся в разметке.

## Состав

Корневая Group section, вводная Group (Subtitle + H2, gap 20), Group содержимого с двумя колонками. В каждой колонке изображение, H3 и Paragraph. Gap между группами 60, padding секции 70; соотношение соответствует ADR-0051. Изображения отображаются в пропорции 4:3 с object-fit cover, колонки используют стандартную адаптивность WordPress.

## Содержимое

Subtitle, H2, подписи H3, описания и alt заполняются под задачу. Текущие тексты нейтральны для интерьерного контента, без названия бизнеса, якорей или ID объектов сайта. Фотографии сохранены как демонстрационные материалы, не подтверждают выполненные работы компании. После замены фото обновить alt.

## Файлы и зависимости

pattern.php, style.css и assets/images/kitchen-light.jpg, kitchen-detail.jpg. Требуются core/group, columns, column, image, heading, paragraph; style variation subtitle; токены base/contrast и spacing 20/60/70. Для текущего Subtitle dot также нужны muted/primary и его CSS. Категория features должна быть зарегистрирована темой.

## Установка

Перенести pattern.php в patterns/content-two-images.php темы. Скопировать обе фотографии в assets/images/content-two-images/ темы: этот путь используется get_theme_file_uri в паттерне. Добавить правила style.css в подключаемый assets/blocks/image.css через wp_enqueue_block_style для core/image. Установить выбранный subtitle. Вставить обычный pattern; экземпляры независимы. Не создавать symlink или runtime-зависимость от library.

Класс furniture-demo-media сохранён для совпадения с проверенным проектным CSS; он обозначает оформление изображений и не привязан к ID страницы или бренду. При переименовании класса одновременно адаптировать CSS и разметку.
