# Header: Site Title и Navigation

- **Статус:** Черновик
- **Pattern slug:** celestial/header-title-navigation

## Назначение

Простой хедер сайта: название слева, меню справа. Подходит для короткого названия и небольшого меню.

## Состав

Внешний Group full-width с constrained layout ограничивает внутреннюю строку шириной contentSize. Внутренний Group использует flex, space-between и перенос. Site Title не создаёт заголовок H1. Navigation использует мобильное overlay-меню и стандартный выбор меню WordPress без ref и заданных вложенных ссылок.

## Содержимое

Название берётся из настроек сайта. Navigation использует доступное сохранённое меню через стандартный fallback WordPress; при отсутствии меню применяется fallback со списком страниц. Конкретное сохранённое меню можно выбрать в настройках Navigation проекта. В pattern нет ID меню и привязки к базе конкретного сайта. На узком экране используется кнопка открытия меню; длинное название может переноситься.

## Зависимости

Стандартные блоки Group, Site Title и Navigation; fallback может использовать Page List. Токен spacing 50; contentSize и root padding из theme.json. Дополнительный CSS, PHP-функции и style variations не нужны.

## Перенос и адаптация

Перенести pattern.php в patterns/header-title-navigation.php темы. В parts/header.html подключить celestial/header-title-navigation через core/pattern. Семантический header задаёт template-part в шаблонах. Адаптировать название сайта и содержимое Navigation. Работа темы не зависит от library.

Это обычный файловый pattern; общей частью всех шаблонов является header template part. Pattern сам по себе не синхронизирует отдельно вставленные экземпляры.
