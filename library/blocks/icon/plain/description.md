# Plain

Базовый контракт core/icon: рисунок 2rem, цвет contrast, без подложки. Установка описана в ../README.md; базовые файлы — ../base.json и ../base.css. Отдельного уровня вариантов базового оформления сейчас нет. Иконки выбираются из Lucide по смыслу блока.

Проверки: размер и цвет применены в проекте; владелец подтвердил работу. Повторно проверить контраст и inline-настройки при переносе.
