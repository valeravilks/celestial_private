# Rounded square: Default

- **Статус:** Черновик
- **Блок:** core/icon
- **Style variation:** rounded-square
- **Класс:** is-style-rounded-square

## Назначение

Иконка в скруглённой квадратной подложке. Рисунок 2rem/base, контейнер 4.5rem/primary; радиус 0.5rem. Саму иконку выбирать из установленного Lucide по смыслу содержимого.

## Зависимости и перенос

Нужны ../../base.json и ../../base.css, токены primary/base/contrast и settings.custom.icon. Перенести готовый style.css в CSS Icon проекта после базовых правил, зарегистрировать стиль rounded-square. style.json описывает цвет и радиус; геометрия контейнера и явный цвет SVG задаются CSS. Установка — ../../README.md. Не подключать library напрямую и не дублировать SVG коллекции.
