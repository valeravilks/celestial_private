# Subtitle: Dot

- **Статус:** Черновик
- **Блок:** core/paragraph
- **Style variation:** subtitle
- **Класс:** is-style-subtitle

## Назначение и оформление

Короткая вводная подпись над заголовком секции. Текст приглушённый (muted); перед ним декоративная круглая точка primary через ::before. Типографика: sm, bold, wide, snug. Размер точки и промежуток после неё — spacing 20; margin-inline-end учитывает направление текста.

## Файлы и зависимости

style.json описывает цвет текста и типографику; style.css содержит полный выбранный стиль, включая псевдоэлемент. Нужны токены color muted/primary, font-size sm, custom font-weight bold, letter-spacing wide, line-height snug и spacing 20. На других фоновых цветах проверить контраст текста и видимость точки.

## Установка

Выбрать dot как единственную реализацию subtitle для проекта. Перенести style.css в assets/blocks/paragraph.css темы и подключить через wp_enqueue_block_style для core/paragraph. Зарегистрировать стиль subtitle через register_block_style; сохранять стабильный класс is-style-subtitle. style.json служит декларацией оформления для адаптации; его slug не означает отдельную глобальную вариацию темы. Не устанавливать plain и dot одновременно под одним именем. Не создавать зависимость сайта от library.

## Содержимое и доступность

Использовать короткий текст; точка не несёт самостоятельного смысла и не заменяет подпись. Пустой content псевдоэлемента не добавляет озвучиваемый символ. Оформление не меняет HTML Paragraph на заголовок.
