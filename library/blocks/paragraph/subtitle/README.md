# Subtitle

- **Блок WordPress:** core/paragraph
- **Style variation:** subtitle
- **Класс в проекте:** is-style-subtitle
- **Состояние:** добавлены реализации plain и dot

Subtitle — стиль Paragraph для короткой вводной подписи, например над заголовком секции. Это style variation, а не новый тип блока и не альтернативный HTML-уровень заголовка.

Библиотека может содержать реализации с точкой, линией, подложкой или другой согласованной типографикой. Для конкретного проекта выбирается одна реализация, сохраняющая имя `subtitle`. Паттерны используют стабильное имя, не привязываясь к библиотечному названию dot/line.

Назначение, допустимое содержимое и параметры адаптации каждой реализации будут описаны при наполнении. В текущей теме выбран dot: точка primary и текст muted. Plain сохранён как альтернатива.

- [Plain](plain/description.md) — без декора.
- [Dot](dot/description.md) — круглая точка перед подписью.
