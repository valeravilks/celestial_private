# Внутренняя библиотека Celestial

Библиотека хранит варианты для разработки сайтов. Она находится вне `wordpress/`, сохраняется в приватной истории проекта и не передаётся клиенту. В отличие от локальной папки `references/`, это поддерживаемая часть системы.

## Структура

- [blocks/](blocks/README.md) — style variations блоков и альтернативные реализации каждой variation.
- [sections/](sections/README.md) — готовые композиции в виде WordPress patterns.
- templates/ — шаблоны описания [style variation](templates/style-variation.md), [её реализации](templates/variant.md) и [секции](templates/section.md).

```text
blocks/<block>/<style-variation>/<variant>/
sections/<section>/
```

Например, `blocks/paragraph/subtitle/dot/` — реализация с точкой для style variation `subtitle` блока `core/paragraph`. `line/` — альтернативная реализация того же стиля. Это не два разных стиля для обязательной установки на сайт.

## Использование

1. Найти подходящую style variation или секцию по назначению и ограничениям.
2. Проверить её статус и зависимости.
3. Выбрать одну реализацию style variation для проекта, адаптировать её к токенам проекта.
4. Перенести в `wordpress/` только нужные код, ресурсы и документацию.
5. Проверить результат в редакторе и на сайте.

Источник истины о выбранном оформлении — фактический код `wordpress/`. Отдельный Project Composition или реестр выбранных вариантов не ведётся. Библиотека не подключается во время работы сайта и не обновляет клиентский код автоматически.

## Наполнение

Созданы структура, шаблоны описаний и секции Header, Footer и шесть секций черновой продуктовой страницы Celestial. Реализованных вариантов style variations пока нет. Subtitle используется как пример организации, а не как зарегистрированный стиль.

Новый элемент добавляется обычным изменением библиотеки, без отдельного ADR, если не меняет принятых принципов. Для карточек использовать статусы «Черновик», «Проверен», «Устарел». Статус «Проверен» требует выполненных проверок, записанных в карточке. Статические PNG-превью не обязательны; демонстрационная среда может быть определена отдельно.

Основные правила: [ADR-0037](../docs/adr/0037-internal-design-library.md), [ADR-0038](../docs/adr/0038-style-variation-alternatives.md), [ADR-0039](../docs/adr/0039-project-source-of-truth.md).
