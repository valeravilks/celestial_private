# Celestial3

Внутренняя система разработки сайтов на WordPress/Gutenberg с собственной FSE-темой. [Цель](docs/project-goal.md) — получать готовые сайты по краткому запросу с понятным владельцу кодом и возможностью самостоятельно собирать страницы.

- [Текущая архитектура и ограничения](docs/architecture.md).
- [Запуск WordPress, wp-env и установка](wordpress/README.md).

## Каталоги

wordpress/ — самостоятельный клиентский проект: тема без сборки и плагин с собственными инструментами. library/ — приватные переиспользуемые реализации; [порядок работы](docs/library-workflow.md). references/ — локальные приватные наработки, исключённые из Git и общего поиска; чтение только по явному запросу. После клонирования каталог можно создать отдельно.

Клиенту передаётся отдельная подготовленная копия wordpress/, без внутренней документации, библиотеки и истории Git. База, медиа и сборка плагина требуют подготовки по [инструкции передачи](docs/maintenance.md). Локальный сайт — http://localhost:8888/; параметры и команды описаны в WordPress-проекте.
