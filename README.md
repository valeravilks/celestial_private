# Celestial3

Система разработки сайтов, которая развивается постепенно на основе архитектурных решений, зафиксированных в Architecture Decision Records (ADR).

[Цель и философия Celestial](docs/project-goal.md) — получать готовые WordPress-сайты по краткому запросу, сохраняя понятный владельцу код, принятые подходы и возможность самостоятельно собирать страницы.

Технологии, компоненты и способы работы выбираются по мере появления конкретных задач. Первое принятое решение — сам подход к развитию системы через ADR.

## Основа разработки

[Внутренняя библиотека](library/README.md) хранит альтернативные реализации style variations и секции. В `wordpress/` попадает только выбранный код; он является источником истины о сайте.

[Текущая архитектура](docs/architecture.md) описывает принятые технологии, их назначение, структуру репозитория и состояние реализации.

Будущие сайты разрабатываются на WordPress с редактором Gutenberg и блочной темой с поддержкой Full Site Editing (FSE).

Каталог [`wordpress/`](wordpress/) содержит минимальную FSE-тему Celestial в `theme/` и плагин Celestial в `plugin/`. Локальное окружение настроено через `wp-env`.

## Передача клиенту

Передаваемые исходники сайта находятся в [`wordpress/`](wordpress/). Клиент получает отдельную копию содержимого этого каталога. Конфигурации проекта находятся внутри `wordpress/`, а wp-env установлен глобально. Внутренняя документация и история репозитория остаются приватными. Граница определена в [ADR-0014](docs/adr/0014-plugin-scoped-development-tools.md).

## Локальный запуск

Требуются запущенный Docker, совместимые с глобальным wp-env Node.js и npm (проверено на Node.js 24.21.0 и npm 11.19.0). Из корня репозитория сначала перейти в `wordpress/`:

```sh
cd wordpress
npm install --global @wordpress/env@11.17.0
wp-env start
```

Сайт: [localhost:8888](http://localhost:8888/). Админка: [localhost:8888/wp-admin](http://localhost:8888/wp-admin/). Локальные учётные данные wp-env: `admin` / `password`.

Конфигурация [.wp-env.json](wordpress/.wp-env.json) подключает тему и плагин; после запуска тема автоматически активируется. Остановка: `wp-env stop`.

## Архитектурные решения

Локальная папка `references/` предназначена для приватных наработок из других проектов. Она исключена из Git и клиентских поставок; агент обращается к ней по явному запросу. После клонирования её можно создать командой `mkdir -p references`.

[Реестр ADR](docs/adr/README.md) содержит принятые решения и шаблон для новых записей.

[Открытые вопросы и идеи](docs/questions/README.md) содержат отложенные темы, их статусы и результаты обсуждения.

ADR и их реестр — единственный механизм фиксации архитектурных решений проекта.

После добавления ADR или изменения его статуса агент сохраняет связанные изменения локальным Git-коммитом. Публикация репозитория выполняется только по отдельному указанию.
