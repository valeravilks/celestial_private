# Celestial — Typography

Типографическая система для корпоративных сайтов на WordPress FSE.

Typography объединяет шрифтовые семейства, размеры, веса, межстрочные интервалы и межбуквенные расстояния. Эти токены описывают доступные значения, а не конкретные компоненты.

## Font Family

| Token | Значение | Назначение |
|---|---|---|
| `ubuntu` | `Ubuntu, sans-serif` | Основное семейство интерфейса и контента Celestial. |
| `roboto` | `Roboto, sans-serif` | Дополнительное семейство для отдельных интерфейсных или контентных задач. |

Оба семейства подключаются локально и поддерживают веса `400` и `700`.

## Font Size

| Token | Значение | ≈ px* | Назначение |
|---|---:|---:|---|
| `sm` | `0.875rem` | 14px | Подписи, metadata, примечания, helper text и второстепенная информация. |
| `md` | `1rem` | 16px | Базовый размер основного текста, интерфейса и небольших заголовков. |
| `lg` | `1.25rem` | 20px | Небольшие заголовки, lead и выделенный текст. |
| `xl` | `1.5rem` | 24px | Малый заголовочный размер. |
| `2xl` | `1.75rem` | 28px | Средний заголовочный размер. |
| `3xl` | `2rem` | 32px | Крупный заголовочный размер. |
| `4xl` | `2.5rem` | 40px | Самый крупный базовый размер системы, основные заголовки страниц. |

\* При стандартном размере шрифта браузера, когда `1rem ≈ 16px`.

## Text Color

Цвет текста задаётся глобально в `styles.color.text` файла `theme.json`:

```json
"styles": {
  "color": {
    "text": "var:preset|color|contrast"
  }
}
```

Поэтому Paragraph, Heading и другие текстовые элементы используют цвет `contrast` через глобальное наследование. Цвет не задаётся отдельно внутри каждого текстового блока.

## Default Mapping

| Элемент | Font Size | Font Weight | Line Height |
|---|---|---:|---:|
| `H1` | `4xl` | `700` | `tight` |
| `H2` | `3xl` | `700` | `tight` |
| `H3` | `2xl` | `700` | `tight` |
| `H4` | `xl` | `700` | `tight` |
| `H5` | `lg` | `700` | `snug` |
| `H6` | `md` | `700` | `snug` |
| Paragraph | `md` | `400` | `normal` |
| Caption / metadata / helper text | `sm` | `400` | `normal` |

Это default mapping Celestial, а не ограничение использования токенов. Иерархия текста определяется сочетанием размера, веса, line-height, letter-spacing и spacing.

## Font Weight

| Token | Значение | Назначение |
|---|---:|---|
| `regular` | `400` | Основной текст, paragraph, metadata и обычные интерфейсные элементы. |
| `bold` | `700` | Заголовки, акцентные элементы и важные labels. |

В первой версии Celestial используются только веса, для которых подключены локальные font files. Вес `500` не добавляется без отдельного файла шрифта.

## Токены в `theme.json`

В отличие от `fontSizes` и `fontFamilies`, WordPress не предоставляет отдельную нативную preset-палитру для `fontWeight`, `lineHeight` или `letterSpacing`.

Поэтому эти значения следует регистрировать через `settings.custom` в `theme.json`:

```json
{
  "settings": {
    "custom": {
      "fontWeight": {
        "regular": "400",
        "bold": "700"
      },
      "lineHeight": {
        "tight": "1.2",
        "snug": "1.4",
        "normal": "1.6",
        "relaxed": "1.75"
      },
      "letterSpacing": {
        "normal": "0",
        "wide": "0.08em"
      }
    }
  }
}
```

WordPress создаст CSS custom properties, например:

```css
--wp--custom--font-weight--regular: 400;
--wp--custom--font-weight--bold: 700;
--wp--custom--line-height--normal: 1.6;
```

В стилях `theme.json` эти токены используются через `var:custom`:

```json
{
  "styles": {
    "typography": {
      "fontWeight": "var:custom|font-weight|regular",
      "lineHeight": "var:custom|line-height|normal"
    },
    "elements": {
      "heading": {
        "typography": {
          "fontWeight": "var:custom|font-weight|bold",
          "lineHeight": "var:custom|line-height|tight"
        }
      }
    }
  }
}
```

`fontFace.fontWeight` и `settings.custom.fontWeight` имеют разные задачи. `fontFace.fontWeight` описывает реально подключённые файлы шрифта, а `settings.custom.fontWeight` создаёт дизайн-токены для повторного использования.

Controls типографики скрыты общей политикой редактора.

## Line Height

| Token | Значение | Назначение |
|---|---:|---|
| `tight` | `1.2` | Крупные заголовки и плотная заголовочная иерархия. |
| `snug` | `1.4` | Небольшие заголовки, карточки и компактный UI-текст. |
| `normal` | `1.6` | Основной текст и стандартный контент. |
| `relaxed` | `1.75` | Длинные текстовые фрагменты, где важна дополнительная читаемость. |

## Letter Spacing

| Token | Значение | Назначение |
|---|---:|---|
| `normal` | `0` | Обычный текст и большинство заголовков. |
| `wide` | `0.08em` | Небольшие uppercase labels, например `H6` или eyebrow-текст. |

Letter spacing применяется точечно. Его не следует добавлять ко всему тексту или использовать для компенсации неподходящего font size.

## Базовый размер и `rem`

`md = 1rem` — базовая точка типографической системы. При стандартных настройках браузера это примерно `16px`.

Размеры хранятся в `rem`, чтобы система учитывала пользовательские настройки размера шрифта. Не следует задавать размер `html` только ради искусственного пересчёта `rem`, например через `font-size: 62.5%`.

## Правила

1. Font Size, Font Weight, Line Height и Letter Spacing — независимые токены, которые комбинируются в стилях текста.
2. Токены не называются `h1`, `h2` и другими именами компонентов или HTML-элементов.
3. `H1 → 4xl`, `H2 → 3xl` и другие соответствия — default mapping, а не обязательное значение.
4. Размер заголовка и его HTML-уровень — разные понятия. Один размер может использоваться несколькими элементами.
5. `H6` может использовать `md`; его иерархия создаётся через вес, line-height, spacing и контекст.
6. Для текста следует сначала выбрать подходящий размер и line-height, затем при необходимости уточнить вес и letter-spacing.
7. `5xl` и дополнительные веса пока не добавляются без подтверждённой потребности и соответствующих font files.


## Реализация в теме

Размеры и семейства зарегистрированы в `theme.json`. Файлы шрифтов хранятся локально в `assets/fonts/ubuntu/` и `assets/fonts/roboto/`; загрузка с внешнего сервиса не требуется. Базовый текст использует Ubuntu, md, regular и normal. H1–H4 используют tight, H5–H6 — snug. HTML-уровень выбирается по структуре документа, независимо от визуального размера.

Типографические controls скрыты глобально; токены и CSS сохраняются для готового оформления.

Для slugs `2xl`, `3xl`, `4xl` WordPress генерирует CSS-переменные `--wp--preset--font-size--2-xl`, `--wp--preset--font-size--3-xl`, `--wp--preset--font-size--4-xl`. В стилях H1–H3 используются прямые ссылки на эти переменные, чтобы соответствовать сгенерированным именам.

## Редактор

[Общая политика редактора](editor-controls.md) скрывает настройки дизайна глобально. Токены этого документа сохраняются для оформления темы и готовых паттернов; ручной выбор значений в стандартных controls не предлагается.
