# Celestial — Цветовая система

Цветовая система для корпоративных сайтов на WordPress FSE.

## Где создавать цвета в `theme.json`

Цветовые токены создаются в файле `wordpress/theme/theme.json` внутри `settings.color.palette`:

```json
"settings": {
  "color": {
    "palette": [
      {
        "slug": "primary",
        "name": "Primary",
        "color": "#007A58"
      }
    ]
  }
}
```

Для нового цвета добавляется новый объект с уникальными `slug`, `name` и `color`. WordPress создаёт переменную вида `--wp--preset--color--primary`.

## Palette

### Brand

  -----------------------------------------------------------------------
Token                               Назначение
  ----------------------------------- -----------------------------------
`primary`                           Главный фирменный цвет бренда.

`secondary`                         Второй фирменный цвет бренда.

`accent`                            Цвет для редких визуальных акцентов
и привлечения внимания.
  -----------------------------------------------------------------------

### Foundation

  -----------------------------------------------------------------------
Token                               Назначение
  ----------------------------------- -----------------------------------
`base`                              Основной фон / базовая поверхность
сайта.

`contrast`                          Основной foreground и цвет текста,
контрастный к `base`.
  -----------------------------------------------------------------------

### Surface

  -----------------------------------------------------------------------
Token                               Назначение
  ----------------------------------- -----------------------------------
`surface`                           Альтернативная нейтральная
поверхность: секции, карточки,
подложки.

  -----------------------------------------------------------------------

### Neutral

  -----------------------------------------------------------------------
Token                               Назначение
  ----------------------------------- -----------------------------------
`muted`                             Foreground пониженной визуальной
важности: подписи, metadata,
примечания, helper text,
второстепенные иконки.

  -----------------------------------------------------------------------

### State

Token       Назначение
  ----------- -----------------------------
`success`   Успешное состояние.
`warning`   Предупреждение.
`error`     Ошибка / опасное состояние.

## Базовые контрастные пары

  -----------------------------------------------------------------------
Background              Foreground              Назначение
  ----------------------- ----------------------- -----------------------
`base`                  `contrast`              Основной текст.

`base`                  `muted`                 Вторичный текст.

`surface`               `contrast`              Основной текст на
альтернативной
поверхности.

`surface`               `muted`                 Вторичный текст на
альтернативной
поверхности.

`contrast`              `base`                  Инвертированный текст.
-----------------------------------------------------------------------

При подборе конкретных цветов эти пары должны быть гарантированно
читаемыми.

-   Обычный текст: контраст не ниже **4.5:1**.
-   Крупный текст: не ниже **3:1**.
-   Значимые нетекстовые UI-элементы: ориентир **3:1**, когда применимо
	WCAG 1.4.11.
-   Сочетания `primary`, `secondary` и `accent` с foreground проверяются
	отдельно для каждого проекта.

## Background

Основные разрешённые фоновые цвета:

-   `base` --- основной;
-   `surface` --- альтернативный нейтральный;
-   `contrast` --- инвертированный;
-   `primary` --- фирменный;
-   `secondary` --- второй фирменный;
-   `accent`, `success`, `warning`, `error` --- локально, по назначению.

## Короткие правила

1.  **Palette --- это набор доступных красок, а не названия
	компонентов.**
2.  `base ↔ contrast` --- фундаментальная пара темы.
3.  `contrast` должен работать как текст на `base` и `surface`.
4.  `muted` должен оставаться читаемым на `base` и `surface`.
5.  Наличие двух цветов в Palette не означает, что их разрешено сочетать
	без проверки контраста.
6.  `border` не является отдельным Palette token --- цвет границ
	выбирается из палитры по требуемой выразительности.
7.  `surface-alt` пока не используется.
8.  `background`, `button-primary`, `card-background`, `heading-color` и
	подобные названия --- это применение цветов, а не Palette tokens.
9.  Градиенты в эту версию системы пока не входят.

## Стартовая палитра темы

Это начальные значения Celestial. Для конкретного проекта их можно адаптировать под бренд, сохраняя роли токенов и проверяя контраст заново.

| Токен | Значение |
| --- | --- |
| `primary` | `#007A58` |
| `secondary` | `#3156A3` |
| `accent` | `#FFC107` |
| `base` | `#FFFFFF` |
| `contrast` | `#242628` |
| `surface` | `#F4F6F8` |
| `muted` | `#58616A` |
| `success` | `#167341` |
| `warning` | `#855600` |
| `error` | `#B42318` |

По умолчанию фон сайта использует `base`, текст — `contrast`. Для фона `primary` и `secondary` использовать проверенный светлый foreground `base`; для `accent` — тёмный `contrast`. Цвета состояний `success`, `warning` и `error` проверены как текст на `base` и `surface`, а также как фон со светлым текстом `base`. Состояние должно быть понятно по подписи или значку, а не только по цвету.

Цветовые токены зарегистрированы в `settings.color.palette` файла `theme.json`. Доступность controls редактора определяется отдельно; этот документ не задаёт их ограничения.
