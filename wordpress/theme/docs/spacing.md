# Celestial — Spacing Scale

Система отступов и расстояний для корпоративных сайтов на WordPress FSE.

Celestial использует практичную шкалу на базе `4px`: малые значения дают точный контроль над интерфейсом, а основные шаги следуют привычному ритму `8px`. Крупные значения становятся fluid и адаптируются к ширине экрана.

## Где создавать spacing-токены в `theme.json`

Токены расстояний создаются в файле `wordpress/theme/theme.json` внутри `settings.spacing.spacingSizes`:

```json
"settings": {
  "spacing": {
    "spacingSizes": [
      {
        "slug": "40",
        "name": "40",
        "size": "1rem"
      }
    ]
  }
}
```

Для нового значения добавляется новый объект с уникальными `slug`, `name` и `size`. WordPress создаёт переменную вида `--wp--preset--spacing--40`.

## Spacing

| Token | Значение | ≈ px | Назначение |
|---|---:|---:|---|
| `10` | `0.25rem` | 4px | Минимальный зазор: иконки, компактные UI-элементы, тонкие внутренние отступы. |
| `20` | `0.5rem` | 8px | Малый внутренний отступ и gap между близкими элементами. |
| `30` | `0.75rem` | 12px | Компактные группы элементов, небольшие отступы в компонентах. |
| `40` | `1rem` | 16px | Базовый отступ системы, стандартный padding и gap. |
| `50` | `1.5rem` | 24px | Умеренный отступ между элементами и содержимым блоков. |
| `60` | `2rem` | 32px | Отступ между связанными блоками и крупный внутренний padding. |
| `70` | `clamp(2.5rem, 5vw, 4rem)` | 40–64px | Отступ между крупными блоками и секциями. |
| `80` | `clamp(4rem, 8vw, 6rem)` | 64–96px | Большой вертикальный отступ между секциями страницы. |
| `90` | `clamp(6rem, 10vw, 8rem)` | 96–128px | Максимальный spacing для hero-блоков и крупных разделов. |

Все приблизительные значения в пикселях рассчитаны для корневого размера шрифта `16px`. При других пользовательских настройках rem-значения изменяются соответственно.

## Принцип шкалы

Первые значения используют фиксированные `rem`-шаги:

```text
4px  → 8px → 12px → 16px → 24px → 32px
```

Это не строгая шкала только из кратных 8px. Значение `4px` оставлено для точных компактных интерфейсных расстояний, а `8px`, `16px`, `24px` и `32px` формируют основной рабочий ритм.

Начиная с `70`, значения становятся fluid через `clamp()`. Это позволяет крупным отступам уменьшаться на небольших экранах и расти на больших, сохраняя заданные минимальные и максимальные границы.

## Базовое применение

| Сценарий | Рекомендуемый spacing |
|---|---|
| Gap между иконкой и текстом | `10` / `20` |
| Padding кнопки | `20` / `40` |
| Gap между кнопками или ссылками | `40` |
| Внутренний padding карточки | `40` / `50` |
| Gap между элементами блока | `40` / `50` |
| Расстояние между связанными блоками | `50` / `60` |
| Расстояние между секциями | `70` / `80` |
| Hero и крупные разделы | `80` / `90` |

Это default mapping Celestial, а не ограничение использования токенов. Конкретный компонент может использовать другой токен, если этого требует его композиция.

## Единицы измерения

Фиксированные значения хранятся в `rem`, чтобы spacing оставался относительным к размеру шрифта корневого элемента и учитывал пользовательские настройки масштаба.

Крупные значения используют `clamp()` для responsive-поведения:

```css
clamp(minimum, preferred, maximum)
```

Например, `70` постепенно изменяется от `2.5rem` до `4rem` в зависимости от ширины viewport.

## Правила

1. Spacing Scale — это набор доступных расстояний, а не названия компонентов.
2. Числовые токены `10–90` сохраняются в формате WordPress presets и не привязываются к конкретным элементам интерфейса.
3. `10` используется только для компактных случаев; базовый рабочий ритм начинается с `20` и `40`.
4. Не следует добавлять новые значения между существующими токенами без подтверждённой потребности.
5. Для крупных вертикальных отступов следует предпочитать `70–90`, чтобы сохранить адаптивность на разных экранах.
6. Значения spacing не должны использоваться для компенсации неправильного `line-height`, размеров шрифта или структуры layout.

## Итоговая структура

```text
FIXED SPACING
├── 10 → 0.25rem → 4px
├── 20 → 0.5rem  → 8px
├── 30 → 0.75rem → 12px
├── 40 → 1rem     → 16px
├── 50 → 1.5rem   → 24px
└── 60 → 2rem     → 32px

FLUID SPACING
├── 70 → clamp(2.5rem, 5vw, 4rem)
├── 80 → clamp(4rem, 8vw, 6rem)
└── 90 → clamp(6rem, 10vw, 8rem)
```

## Ограничения редактора

В `settings.spacing` установлены:

- `defaultSpacingSizes: false` — стандартная шкала WordPress отключена.
- `customSpacingSize: false` — произвольный ввод расстояний отключён.
- `blockGap: true` — управление расстоянием между блоками включено для поддерживающих его блоков.

В стандартных spacing-controls доступны только девять пресетов темы `10–90`. Доступность padding и margin для конкретных блоков определяется отдельно. Значения отступов сайта и ширина layout этим документом не устанавливаются. Ограничения UI не удаляют ранее сохранённые произвольные значения и не управляют нестандартными controls сторонних блоков.

## Поведение fluid-токенов

`clamp()` меняет значение только между своей минимальной и максимальной границами. При `1rem = 16px`:

| Токен | Начало роста, ширина viewport | Достижение максимума |
| --- | --- | --- |
| `70` | `800px` | `1280px` |
| `80` | `800px` | `1200px` |
| `90` | `960px` | `1280px` |

Ниже этого диапазона используется минимум, выше — максимум. Поэтому на узких мобильных экранах значения равны соответственно `2.5rem`, `4rem` и `6rem`.
