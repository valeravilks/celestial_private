# Accordion для FAQ

Группы раскрывающихся вопросов и аналогичного содержимого создаются штатными блоками core/accordion → core/accordion-item → core/accordion-heading + core/accordion-panel. Не подменять их набором Details или собственным переключателем. Правило не является запретом семантического Details во всех других сценариях.

Уровень заголовков выбирать по окружению: после H2 секции вопросы имеют H3. Сохранять штатные кнопки, связь с панелями, клавиатурное управление и поведение WordPress. Текущий FAQ главной — четыре вопроса в одном Accordion; несколько панелей могут открываться независимо.

Дополнительный CSS главной находится в assets/blocks/accordion.css, ограничен .wardrobe-faq и подключается через celestial_theme_register_block_styles на init. Базовые токены остаются в theme.json. Собственного JS и нового плагина нет. Controls дизайна не включаются.

Проверять поддержку четырёх типов блоков в установленном WordPress, раскрытие/закрытие мышью и клавиатурой, aria-expanded, видимость ответа, узкий экран и валидацию сохранённой разметки в редакторе. При отсутствии поддержки не подменять механизм молча. Для текущего FAQ frontend проверен; полный цикл сохранения Gutenberg остаётся непроверенным — см. [отчёт страницы](../wardrobe-landing.md).
