# Celestial — Layout

Система ширины и структуры страницы для корпоративных сайтов на WordPress FSE.

Layout определяет общий каркас страницы: ширину обычного контента, широких секций, full-width блоков и боковые отступы страницы. Это не стили отдельных компонентов, а общая рамка, внутри которой строятся шаблоны, паттерны и блоки.

## Где создавать layout-настройки в `theme.json`

Основные размеры layout создаются в файле `wordpress/theme/theme.json` внутри `settings.layout`:

```json
"settings": {
  "layout": {
    "contentSize": "1200px",
    "wideSize": "1600px"
  }
}
```

Глобальные боковые отступы страницы задаются в `styles.spacing.padding` и используют spacing-токен:

```json
"styles": {
  "spacing": {
    "padding": {
      "left": "var(--wp--preset--spacing--40)",
      "right": "var(--wp--preset--spacing--40)"
    }
  }
}
```

## Page Widths

| Настройка | Значение | Назначение |
|---|---:|---|
| `contentSize` | `1200px` | Основная ширина обычного контента, текста, форм и стандартных секций. |
| `wideSize` | `1600px` | Расширенная ширина для сеток, медиа, CTA и крупных визуальных секций. |

## Alignments

| Alignment | Назначение |
|---|---|
| Default | Обычный контент в пределах `contentSize`. |
| `alignwide` | Более широкая секция в пределах `wideSize`, но с сохранённой рамкой страницы. |
| `alignfull` | Полноэкранная секция от края до края: фон, hero, cover и крупные page bands. |

## Root Padding

Боковые отступы страницы используют токен spacing `40`, то есть `1rem` при стандартном размере шрифта браузера.

Верхний и нижний padding корневой страницы остаются `0px`. Вертикальный ритм должен создаваться секциями, блоками и паттернами, а не глобальной рамкой страницы.

`useRootPaddingAwareAlignments` включён, поэтому широкие и full-width блоки корректно взаимодействуют с боковыми отступами корневого layout.

Важно: `useRootPaddingAwareAlignments` задаётся напрямую внутри блока `settings`, а не внутри `settings.layout`:

```json
"settings": {
  "useRootPaddingAwareAlignments": true
}
```

## Базовое применение

```text
Обычный текст и формы       → contentSize
Стандартные группы          → contentSize
Сетки услуг и портфолио     → alignwide
Большие CTA и media-секции  → alignwide
Hero с full-width фоном     → alignfull
Full-bleed background       → alignfull
```

Длинный текст может использовать более узкую локальную ширину для удобства чтения. Это настройка конкретной композиции, а не новый глобальный layout-токен.

## Правила

1. Layout-токены описывают общий каркас сайта, а не отдельные компоненты.
2. Обычный контент по умолчанию использует `contentSize`.
3. `alignwide` применяется, когда секции нужно больше горизонтального пространства, но она должна оставаться визуально ограниченной.
4. `alignfull` используется для полноэкранных фонов и крупных визуальных секций.
5. Боковые отступы должны ссылаться на spacing-токены, а не задаваться случайными значениями.
6. `contentSize` и `wideSize` изменяются только при подтверждённой потребности всего проекта.
7. Не следует создавать отдельные ширины для каждого блока без реальной композиционной необходимости.

## Итоговая структура

```text
LAYOUT
├── contentSize → 1200px
├── wideSize    → 1600px
├── default     → contentSize
├── alignwide   → wideSize
├── alignfull   → viewport width
└── root padding
    ├── left  → spacing 40
    └── right → spacing 40
```
