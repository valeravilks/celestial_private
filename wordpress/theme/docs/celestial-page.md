# Страница Celestial

Первый черновик продуктовой страницы: Hero, преимущества, состав проекта, процесс, вопросы и контакт. Контент — предварительное предложение для согласования, не утверждённые коммерческие условия. Контакт явно оставлен незаполненным; до публикации нужно добавить реальный способ связи и согласовать тексты.

Главная страница редактируется как обычная страница WordPress. Вставленные секции — обычные блоки, а не синхронизированные patterns. В редакторе паттерны доступны по названиям «Celestial: …». Каждый экземпляр редактируется самостоятельно. Не вставлять одинаковые якоря повторно на одной странице.

front-page подключает Header, content-front-page и Footer. content-front-page выводит содержимое страницы без дополнительного заголовка: H1 уже есть в Hero.

celestial-page.html содержит исходный набор блоков для повторного заполнения в кодовом редакторе новой страницы. После вставки содержимое живёт в базе WordPress; файл не перезаписывает правки автоматически. При переносе сайта нужна миграция страницы и настройки главной, либо ручная вставка набора в новую страницу.

Кнопки первого экрана ведут к процессу и контактной секции. Форма отправки, рабочий контакт и обработка заявок пока не настроены. Header содержит ссылки на преимущества, процесс и контакт главной страницы; тестовые страницы в меню не выводятся.
