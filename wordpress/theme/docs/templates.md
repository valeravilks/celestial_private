# Шаблоны и части

`templates/*.html` содержат только ссылки на template parts:

```html
<!-- wp:template-part {"slug":"main-index"} /-->
```

Файл части находится в `parts/main-index.html`. Текущая часть содержит исходную разметку основного содержимого и Query.

В шаблоны не добавляются Group, Query, Post Content, ссылки на паттерны или HTML-обёртки. Их место — в `parts/`. Шаблон выбирает части и их порядок; часть определяет содержимое и layout. При необходимости общий контейнер размещается в части, которая включает вложенные части.

При добавлении шаблона:

1. Определить нужные части и создать недостающие файлы в `parts/`.
2. В `templates/` добавить только блоки `core/template-part` с существующими slug.
3. Проверить отсутствие посторонней разметки и блоков в шаблоне, существование частей и отсутствие циклов.
4. Проверить отображение страницы в WordPress.

Состав шаблонов page, single, landing page и 404 будет определяться постепенно. Пользовательские версии шаблонов, сохранённые в базе данных, могут перекрывать исходники — их нужно учитывать при проверке сайта.
