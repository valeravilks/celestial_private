# Шаблоны и части

В `templates/*.html` разрешены только `core/group` и `core/template-part`, на любом уровне вложенности. Group задаёт композицию и layout; template-part подключает содержимое из `parts/`.

```html
<!-- wp:group {"layout":{"type":"default"}} -->
<div class="wp-block-group">
  <!-- wp:template-part {"slug":"content-index"} /-->
</div>
<!-- /wp:group -->
```

Header, footer, Query, Post Content, Heading и другие содержательные блоки находятся в `parts/`. Паттерны подключаются внутри частей. Разметка оболочки Group разрешена; произвольный HTML вне блоков в шаблоне не добавляется. Group необязателен, если композиция не требует контейнера.

При добавлении шаблона:

1. Определить части и создать недостающие файлы в `parts/`.
2. Собрать шаблон из Group и ссылок на существующие части.
3. Рекурсивно проверить разрешённые типы блоков, оболочки Group, разрешение slug частей и отсутствие циклических ссылок.
4. Проверить рендер страницы в WordPress.

## Базовый комплект

Все шаблоны подключают простые header, содержимое и footer. Header подключает файловый pattern celestial/header-title-navigation: название сайта слева и Navigation справа внутри contentSize; Footer подключает файловый pattern celestial/footer-copyright с текстом «© Celestial 2026»; название и год редактируются вручную. Семантические header/footer задаются при подключении частей; main находится внутри части содержимого.

| Шаблон | Часть содержимого | Назначение |
| --- | --- | --- |
| index, home | content-index | Резервный шаблон и список записей |
| page | content-page | Заголовок и содержимое страницы |
| single | content-single | Заголовок и содержимое записи |
| single-landing-page | content-page | Содержимое Landing Page |
| archive | content-archive | Заголовок архива и список записей |
| search | content-search | Заголовок поиска, форма и результаты |
| 404 | content-404 | Сообщение и поиск |

Списки используют наследуемый Query, отрывки, пагинацию и сообщение при отсутствии результатов. Отдельного front-page пока нет: главная использует home либо page в зависимости от настройки чтения. Navigation начинает с Page List опубликованных страниц; проектное меню и сложные секции пока не настроены.

Части зарегистрированы в theme.json. Пользовательские версии шаблонов и частей в базе данных могут перекрывать исходники; перед проверкой учитывать эти версии.
