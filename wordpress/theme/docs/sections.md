# Композиция страниц и секций

## Страница

Каждый файловый шаблон имеет общую core/group с layout default и style.spacing.blockGap = "0". Внутри допустимы только Group и Template Part; содержательные блоки находятся в parts. [Структура шаблонов](templates.md).

Страницы из полноширинных секций также имеют Group с нулевым gap внутри Post Content. Не обнулять глобально интервалы вложенных секций и текстовых блоков.

## Секция

Новая или явно дорабатываемая секция с вводным блоком строится так:

- Корневая Group секции с вертикальным padding.
- Вложенная вводная Group: Subtitle и основной заголовок.
- Отдельная Group основного содержимого: карточки, колонки и другие блоки.

Интервал Subtitle → заголовок меньше интервала вводная Group → содержимое. Межгрупповой интервал не превышает вертикальный padding секции; при разных верхнем и нижнем — меньший. При нулевом padding положительный межгрупповой gap требует пересмотра композиции. Конкретные значения выбирать из [шкалы расстояний](spacing.md), проверяя соотношение на разных ширинах при fluid-токенах. Например 20 < 50 ≤ 70 — пример, а не обязательные значения. Внутренние интервалы содержимого задаются отдельно.

Subtitle — style variation core/paragraph, не уровень заголовка. Текст — uppercase, muted, с декоративной точкой primary через CSS. Caption — отдельная вариация для небольших подписей, без точки и uppercase. [Paragraph](blocks/paragraph.md).

## Переиспользуемые patterns

Использовать нейтральные названия, подсказки и категории по назначению (Hero, Benefits, Features, Process, FAQ, Contact). Namespace celestial/ технический. Универсальный исходник не содержит текстов текущего продукта, обязательных якорей, ссылок на чужую секцию или ID объектов сайта. Заполненный текст, уникальные якоря и адреса задаются в странице проекта.

Файловые patterns темы сейчас удалены: готовая главная содержит собственные блоки в базе, а docs/wardrobe-page.html — снимок исходной разметки, который сам базу не обновляет. Header/footer содержат прямые блоки в parts. Наличие описанных правил patterns не означает наличия полного каталога в установленной теме.

## Редактирование

[Controls дизайна скрыты глобально](editor-controls.md), оформление задают исходники. Наличие ограничений UI не доказывает невозможность изменения структуры. Вставленные экземпляры и переопределения базы проверяются отдельно.
