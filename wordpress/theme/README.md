# Celestial

Основная тема проекта по умолчанию — самостоятельная блочная WordPress-тема с поддержкой Full Site Editing (FSE).

## Назначение

Тема отвечает за внешнее представление сайта. Здесь размещаются только необходимые для FSE-темы файлы: блочные шаблоны, части шаблонов, `theme.json`, паттерны оформления, готовые стили и ресурсы. PHP-код, если потребуется, обслуживает только оформление и работу темы.

Типы записей, интеграции, бизнес-логика и возможности, сохраняемые при смене темы, разрабатываются в плагине проекта.

## Без сборки

WordPress использует файлы темы напрямую. Предварительная сборка не требуется и не предусмотрена. У темы нет сборочных npm-зависимостей, компиляторов, bundler-конфигураций и генерируемых каталогов `build/` или `dist/`.

## Паттерны

Встроенные паттерны WordPress Core отключены через `remove_theme_support( 'core-block-patterns' )` в `functions.php` на хуке `after_setup_theme`. Паттерны темы, пользовательские паттерны и ранее вставленное содержимое не удаляются. Это правило отдельно не отключает удалённый каталог WordPress.org.

## Файлы темы

[Гайд по CSS блоков](docs/block-styles.md) описывает подключение дополнительных стилей через `wp_enqueue_block_style`. Пустой `assets/blocks/button.css` служит примером; новые визуальные варианты пока не зарегистрированы.

[Цветовая система](docs/colors.md) описывает 10 токенов, начальную палитру и правила контраста. Основной фон — `base`, основной текст — `contrast`.

[Шкала расстояний](docs/spacing.md) содержит девять пресетов `10–90`: шесть фиксированных и три fluid. Стандартная шкала WordPress и произвольный ввод отключены; выбор Block spacing включён.

[Типографика](docs/typography.md) задаёт локальные Ubuntu/Roboto, семь размеров текста и токены веса и интервалов. Стандартные размеры и произвольный ввод отключены.

[Layout](docs/layout.md) задаёт ширины `1200/1600px`, боковые отступы `40` и правила wide/full-width.

[Heading](docs/blocks/heading.md) и [Paragraph](docs/blocks/paragraph.md) описывают настройку стандартных текстовых блоков. Выбор семейства и размера скрыт для этих блоков; цвет доступен из палитры сайта.

- `style.css` — метаданные темы.
- `functions.php` — настройки темы, включая отключение встроенных паттернов Core.
- `theme.json` — настройки блочной темы.
- `templates/index.html` — базовый блочный шаблон.

В локальном окружении проекта тема автоматически активируется после запуска wp-env.
