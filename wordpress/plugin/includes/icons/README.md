# Lucide icons

Встроенный модуль Celestial для стандартного блока WordPress Icon (core/icon). Требуется WordPress 7.1+ с Icon Registration API. При отсутствии API модуль пропускает регистрацию и сообщает администратору о несовместимости; остальные возможности плагина продолжают работать.

## Использование

Добавить блок Icon, открыть Replace и выбрать коллекцию Lucide. Поиск использует английские имена, например check, arrow-right, mail. Для паттернов идентификаторы имеют вид lucide/check. Декоративную иконку оставлять без ariaLabel; смысловой иконке без сопровождающего текста задавать доступную подпись.

Пример разметки: `<!-- wp:icon {"icon":"lucide/check"} /-->`.

Коллекция содержит 2141 SVG (включая алиасы), lucide-static 1.55.0. Стандартная обводка толщиной 2 преобразована в заполненные пути; её толщина не регулируется. Цвет наследуется через currentColor. Общая политика редактора проекта не меняется: модуль не включает controls цвета, размеров и оформления. Выбор самой иконки — выбор содержимого. Отдельные собственные controls core/icon требуют оценки отдельно.

## Файлы и обновление

index.php регистрирует коллекцию lucide и иконки на init. assets/manifest.php — имена и подписи, assets/icons/ — готовые SVG, assets/library.json — версия и число файлов. licenses/Lucide-LICENSE содержит лицензию и атрибуцию Lucide/Feather; включать её в передачу.

Готовые assets и лицензия хранятся в Git и входят в поставку плагина напрямую; npm run build их не генерирует. Обновлять только явной заменой из нового проверенного готового релиза: вместе SVG, manifest, library.json и лицензии. Проверять число и соответствие файлов, регистрацию, SVG-рендер, редактор и сайт. Сохранять идентификаторы уже использованных иконок либо явно мигрировать контент. Не подключать CDN и не импортировать инструменты генерации в этот проект.

Celestial должен оставаться активным: core/icon разрешает зарегистрированные иконки на сервере. Отдельный Lucide Core Icons одновременно активировать не нужно: он использует тот же slug коллекции.

## Проверки текущего переноса

2026-10-14: все 2141 иконки успешно отрендерены wp_get_icon в локальном WordPress 7.1.3. Готовые assets и лицензия сравниваются с релизом побайтно. Проверка редактора подтверждает наличие core/icon и отсутствие общих панелей оформления. Выбор конкретной иконки визуально не подтверждён: canvas нового документа в тестовом браузере пустой.
