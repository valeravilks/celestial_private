# WordPress-проект

- `theme/` — основная блочная FSE-тема Celestial, отвечающая только за внешнее представление и работающая без сборки. Подробности — в [описании темы](theme/README.md).
- `plugin/` — плагин Celestial: PHP-модули, расширения редактора и собственные блоки. [Структура и команды](plugin/README.md).

## Локальная разработка

Все команды выполнять из этого каталога. Требуются запущенный Docker, совместимые с глобальным wp-env Node.js и npm (проверено на Node.js 24.21.0 и npm 11.19.0).

```sh
npm install --global @wordpress/env@11.17.0
wp-env start
```

Сайт: [localhost:8888](http://localhost:8888/). Админка: [localhost:8888/wp-admin](http://localhost:8888/wp-admin/). Локальные учётные данные: `admin` / `password`.

[.wp-env.json](.wp-env.json) подключает `./theme` и `./plugin`; тема автоматически активируется после запуска. Остановка: `wp-env stop`. Дополнительные команды: `wp-env <команда>`.

Глобальную установку выполнить один раз для выбранной версии Node.js. Проверенная версия wp-env — 11.17.0. При переключении версии Node.js через nvm проверить `wp-env --version`: глобальные пакеты относятся к выбранному окружению.

В корне проекта нет `package.json`, lock-файла и `.nvmrc`. Инструменты сборки находятся внутри `plugin/`; перед использованием собственных блоков и ресурсов редактора выполните там `npm ci` и `npm run build`.

## Установка на сервер

1. Установить WordPress с поддержкой блочных тем и `theme.json` версии 3.
2. Скопировать каталог `theme/` в `wp-content/themes/theme/`.
3. Скопировать каталог `plugin/` в `wp-content/plugins/plugin/`.
4. Активировать тему Celestial в разделе «Внешний вид → Темы» и плагин Celestial в разделе «Плагины».

Тема не требует сборки. Плагин требует сборки ресурсов перед поставкой: `npm ci` и `npm run build` внутри `plugin/`, с включением `build/` в устанавливаемый плагин. Разработка и запуск проверены на WordPress 7.1.3.

В проект входят исходники темы и плагина и файлы локального окружения разработки. Ядро WordPress, база данных и загруженные медиафайлы поставляются отдельно.

## Именование PHP-функций

Собственные именованные глобальные функции темы и плагина используют префикс `celestial_` и snake_case: например, `celestial_theme_register_block_styles`. Имена должны быть уникальны между обоими компонентами; при необходимости использовать `celestial_theme_` или `celestial_plugin_`. При ревью проверять префикс, дубли и ссылки на функции в callbacks. Методы классов, анонимные функции и внешние API не переименовываются по этому правилу.

## Навигация по длинным материалам

Для длинных записей и страниц с несколькими разделами рекомендуется блок **Table of Contents** из плагина Celestial. Он строит оглавление по H2/H3 и подсвечивает текущий раздел. В одиночных записях он уже установлен слева от текста; в содержимое обычной страницы его можно вставить отдельно. [Использование и настройка](theme/docs/blocks/table-of-contents.md).
